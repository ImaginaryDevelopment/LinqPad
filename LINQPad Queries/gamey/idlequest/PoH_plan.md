# Plane of Hate farm plan

Source of truth for this sheet: LustreDamus `assets/samples/everquest/zone/Plane-of-Hate.md` (IdleQuest shortnames **`hateplane` / `hateplaneb`**). Class masks cross-checked in idlequest-content `data/items` where noted.

Classic plane. ZEM **1.13×**. Hunt **48–60**. Whole zone is hard — LustreDamus marks **Innoruuk** and most high nameds as **RAID**. Prefer trash idle names below for gear/hour.

**Server rule:** same-account NO DROP transfers. Idle hunts one **exact NPC name**.

**Honest framing vs PoG:** PoG has no exclusive sets for **DRU / PAL / RNG**. Hate also has **no full DRU or PAL armor set** in the LustreDamus class-camp table (and content masks confirm **Imbrued = BRD only**, not hybrid plate for PAL). Hate still has **high-value uniques** for those classes — that is the focus here. Everyone else uses Hate as a **second plane set / upgrade / epic** path while PoG finishes.

2. **`a scorn banshee`** — Bruize Imbrued debt.
3. Split by account hole mass (separate hunts):  
   `Cleric of Innoruuk` · `a kiraikuei` · `an abhorrent` · `a spite golem` · `a forsaken revenant` · `an ashenbone drake`
