# Cursed Captain — Admiral Bleed Build (Prestige 60)

Soulstone Survivors. Tuned for **prestige 60**: **Admiral’s Might** + full unique kit (**Eldritch Grasp**). Primary path is **Bleed detonate** — stack Bleed, delete Lords with **Shrapnel Bomb**, cash **Ghost Ship** windows. **Wrath of the Old Gods** is prestige **70** — ignore Dazed / Cursed Shot peak guides for now.

Unlocked via **Ritual of Heresy** (Unholy Cathedral). See [`Unholy-Cathedral.md`](Unholy-Cathedral.md).

## Why Admiral Bleed (not Iron Tide / not Jaws / not Wrath)

- **Wrath of the Old Gods** is P70 — best raw crit stats, but you do not have it yet
- **Admiral’s Might** is the cleanest Bomb / Bleed package: **Cannon Barrage** + **Fleet Strike** + native Swing / Thrust Bleed tools
- **Shrapnel Bomb** turns thick Bleed into Lord / Overlord delete — same win condition as Assassin / Monkey King bomb paths
- **Kraken’s Rum** + Ghost Ship Fragility stack free damage amp on every path
- **Curse of the Depths** + weapon Cursed stacks → ghost **tentacles** (extra clear while you kite)
- Iron Tide Ammunition and Jaws crit are real alts — see below

## Character notes

| Trait | Value |
| --- | --- |
| Max HP | −10 |
| Crit chance | +5% |
| Crit damage | +20% |
| Experience | +15% |

**Skill types:** Blast · Bomb · Projectile · Swing · Thrust

**Cursed (buff):** many Captain skills grant **Cursed** stacks. At **20** stacks, consume to summon a fighting **tentacle** (max **7**, long duration). Tentacles are free clear — lean into skills that grant Cursed.

**Ghost Ship (ascension):** ~36s into a match a bell rings → marked treasure zone. Stand in it → ship’s wheel drops → pick up to summon the **Ghost Ship**: +25% crit chance, +45% damage, cannons hit priority targets and apply **Fragility**. Green flames from kills during the ship extend duration — scoop them like XP.

**Playstyle:** mid-range cannon kite. Stack Bleed → Shrapnel on Lords. Claim Ghost Ship on Lord waves. Class +15% XP makes prestige farming fast; fix −10 HP with a few max HP passives.

- Do not wait for Wrath skills — they will not appear until P70 / craft.

2. **Shrapnel Bomb** + **Kraken’s Rum**

## Passives — take / ban

### Prioritize

1. **Bleed** chain — flat Bleed, Brutal Strikes / stack amplifiers, Dismemberment if crit-online
2. **Cast frequency** / **multicast** / **area** (applicators + Bladestorm)
3. **Damage** on **Shrapnel Bomb** once the board is online
4. **Movement** + **Magnetic**
5. Some **max HP** (class −10; Admiral taxes more early)
6. Bomb / Physical skill-chain upgrades

### Soft-ban / ban

- Main-ailment **Poison / Fire / Doom** greed
- Pure crit greed *before* Bleed + Shrapnel are online (crit is fine later via Disoriented / Ghost Ship)
- **Skill Mastery** for types you already have
- Sitting on Powder Keg as your only Bomb when Shrapnel is available

## How to play a run

1. Weapon Expert → Fleet Strike + Cannon Barrage; lock **Shrapnel Bomb** + **Kraken’s Rum**.
2. Stack Bleed on packs; **Shrapnel** Lords when stacks are thick.
3. When the bell rings, fill the treasure zone → pick the wheel → scoop green flames; dump ship uptime on Lord waves.
4. Let **Cursed** spill tentacles — do not hoard stacks by refusing to cast.
5. Try **Iron Tide Ammo** or **Jaws crit** as sidegrades; Wrath after P70.
