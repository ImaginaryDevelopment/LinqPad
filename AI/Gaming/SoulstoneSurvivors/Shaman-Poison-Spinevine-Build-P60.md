Soulstone Survivors. Tuned for **prestige 60**: Spinevine Poison with **Cobra Totem**, **Stone Spiral**, full ritual tree progress, and Flamelash unlocked but **not** used on this path. No Tharuun’s Lasher yet (prestige 70).

## Why still Spinevine Poison

- Thorn + ritual HP + Savage Pact is still the clean HP-scaling Poison package
- **Cobra Totem** = Poison + Weakness; **Stone Spiral** = damage totem + Colossal (bigger AoE for Corrosion / Acid Rain / Pestilence)
- Flamelash is a full **Burn/crit** pivot, not a Poison upgrade
- Lasher / Quicksand (70) is the next real totem-Poison adjacent unlock

## Skills (final 6–7) — P60 Spinevine Poison

### Core (do not swap)

| Skill | Role |
| --- | --- |
| **Vine Whip** | Pull + Poison + Ancestry |
| **Poisonous Thorn** | HP-scaling Poison (Weapon Expert) |
| **Pestilence** | Poison flood + stack-scaling damage |
| **Cobra Totem** | Poison + **Weakness** + Ancestry |

### Flex slots (2–3)

Skills marked with † need **Skill Mastery: Nature** (foreign Nature — not in Shaman’s native pool otherwise).

| Role | Prefer | Solid swaps (same role) |
| --- | --- | --- |
| **Sustained AoE applicator** | **Acid Rain** | Poison Cloud, Poison Puddle |
| **Extra stacks / detonate** | **Corrosion†** if Mastery: Nature is on; else **Poison Bolt** | Contagion†, Purging Slam†, Poison Puddle, Poison Cloud |
| **Ancestry / area** (7th with Repertory) | **Stone Spiral** | Bull Charge, Shockwave Totem, Light Beam, Arcane Power |

† = requires **Skill Mastery: Nature** on your Versatility bar.

**Corrosion vs Poison Bolt:** **Corrosion** wins when Mastery: Nature is on. **Poison Bolt** is the best native filler without Mastery.

**Stone Spiral vs Bull Charge:** Prefer **Stone Spiral** on this path (Colossal + Ancestry + Fortitude damage). Bull Charge is fine if Spiral is late or you want Dazed/Purity for crit-Poison.

**Example final 6:** Vine Whip · Poisonous Thorn · Pestilence · Cobra Totem · Acid Rain · Corrosion  
**Example final 7 (Repertory):** above + **Stone Spiral**

**Swap rules:**

- Never drop the four **cores** for Flamelash skills (Flaming Spiral / Volcanic Effigy).
- Do not replace **Cobra Totem** with Stone Spiral — Spiral is flex; Cobra is Weakness.
- Prefer **Corrosion** / **Purging Slam** over a second puddle if Mastery: Nature is on.
- **Contagion** / **Purging Slam** are Lord detonates; keep Pestilence unless Repertory is off and you must cut one core (only then, and only with a detonate locked).

### Skill priority while leveling

1. **Poisonous Thorn** (Weapon Expert) + **Vine Whip**
2. **Cobra Totem**
3. **Pestilence**
4. **Corrosion** (or Acid Rain / Poison Bolt)
5. **Stone Spiral** into the last slot (or Bull Charge if Spiral is slow)

## Passives — take / ban

### Prioritize

1. **Max HP** (Thorn + Savage Pact + ritual)
2. **Poison** — Venomous, Corrosive, **Death and Decay**, Infected Wounds
3. **Multicast** / cast frequency / **area** (Colossal helps; stack more)
4. **Movement** + Magnetic (ritual orbs)
5. Crit chance → crit damage
6. Summon / totem count or damage

### Soft-ban / ban

- Main-ailment **Bleed / Fire / Doom** (especially Fire now that Flamelash can tempt you)
- Don’t banish Poison / Nature / max HP / ritual offers

## How to play a run

1. Weapon Expert → Thorn + Vine Whip; lock **Cobra Totem**, then **Pestilence**.
2. Plant Cobras; whip packs into them; add **Stone Spiral** for Colossal coverage.
3. Dance every **ritual** pyre — ghosts are a large damage share at this prestige.
4. Lords: Weakness up, stack Poison, Pestilence / Corrosion / Purging Slam / Contagion.
5. Farm **prestige 70** Lasher if you want Quicksand totem endgame; otherwise keep pushing curses on Spinevine Poison.
