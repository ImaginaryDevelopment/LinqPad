## Why Boomstick Bleed (not Mountains)

Popular late guides lean **Might of the Mountains** (prestige 70). You do not have that yet.

Instead:

- **Trickster’s Boomstick** → **Gunpowder Strike** applies **Bleed** + **Weakness**
- Debuffs (**Exposed**, **Brittle**, **Shattered**, **Weakness**) soften packs and Lords
- **Shrapnel Bomb** finishes by scaling with Bleed stacks
- Huge **area** from weapon + class clears while you collect Yin/Yang for clones

Big AoE monkey: lean into area and cast frequency; crit is secondary on Boomstick (useful mainly for Bleed-on-crit).

## Recommended weapon

### Primary: Trickster’s Boomstick

| Bonus | Notes |
| --- | --- |

### Strong alternate: Immortal’s Staff (Prowess)

If you prefer Slam stacking over bombs: Massive Slam + Spinning Staff + **Expansive Throw** (scales hard with Prowess) + Whirling Defense. See alt section below.

### Situational: Cloudseeker

Crit / Electric path with Electric Strike. Fine for fun; not the recommended P57 clear build.

### Skill priority while leveling

**“Lock early”** = when these show as level-up choices, **take them immediately** and keep them in a skill slot for the rest of the run (do not skip/reroll hoping for something better).

1. **Shrapnel Bomb** and **Gunpowder Strike** first (Bleed engine + detonate)
2. Then fill **Earthquake** / **Light Beam** / other debuff applicators
3. Swap **Trickster Decoy** out as soon as Armor Shatter / Fan of Bombs / Bomb Barrage appears
4. **Whirling Defense** if you want Prowess / armor while bombing

## Passives — take / ban

### Prioritize

1. **Bleed** power, stacks, tick rate, Bleed-on-hit / Bleed-on-crit (**Deep Wounds**, etc.)
2. Debuffs that set up Shrapnel: **Exposed**, **Brittle**, **Shattered**, **Weakness**
3. **Cast frequency**, **multicast**, **area**
4. **Damage** / some crit once Bleed is rolling
5. **Magnetic** + **movement speed**
6. Some **max HP** (Boomstick tax)

### Banish

- Passives that push **Poison**, **Fire**, or **Doom** as your main ailment
- Off-element clutter that steals slots from Bleed / physical / debuff offers
- **Poisonous Blood** if it converts Bleed → Poison (Shrapnel Bomb scales on **Bleed** stacks — converting them weakens your finisher and pollutes the passive pool with Poison offers)

## How to play a run

1. Start Boomstick → keep Gunpowder Strike firing; stack Bleed + Weakness.
2. Pick up **Yin/Yang** orbs whenever safe — clones are free damage.
3. Layer debuffs (Earthquake / Light Beam / Shatter tools), then **Shrapnel Bomb** when Bleed is high.
4. Lords: stay mobile, dump Shrapnel on stacked Bleed, use clones as extra pressure.
5. Drop Decoy as soon as a real Bomb skill shows up.
