# Unholy Cathedral — Unlocks Reference

Soulstone Survivors. What you permanently unlock by playing **Unholy Cathedral** (wave / cycle mode added in Update 12, Aug 2024).

Mode structure (every run): four combat **cycles** → final boss **Mh'thaeus, the Heretic** → rewards (materials, soulstones, etc.). Skills picked in a cycle lock out of later choices that run. After each cycle you pick an **Unholy Power** (stat boost for the rest of the run).

---

## Ritual difficulties (permanent unlock track)

Pick a difficulty when you enter. Complete each once for the major unlocks:

| Ritual | Difficulty | Permanent unlock |
| --- | --- | --- |
| **Ritual of Sin** | Easiest | Achievement: **The Purge – Ritual of Sin** (“Disrupt the Ritual of Sin in the Unholy Cathedral”) |
| **Ritual of Hate** | Mid | Character: **The Demon Hunter** |
| **Ritual of Heresy** | Hardest | Character: **The Cursed Captain** |

**After clearing all three rituals once:** **Ritual of Heresy** gains **Endless** (+1, +2, … scaling). That is a mode unlock, not a new character.

Naming note: some UI / achievement text mixes “Sin” and “Heresy.” In practice:

- **Hate** → Demon Hunter (confirmed on character wiki)
- **Heresy** → Cursed Captain (confirmed on character wiki)
- **Sin** → achievement / first tier clear

## Character unlocks (detail)

### The Demon Hunter — Ritual of Hate

| | |
| --- | --- |
| **How** | Clear Unholy Cathedral on **Ritual of Hate** |
| **Role** | Ranged |
| **Skill types** | Chaos, Shadow, Projectile, Bomb, Blast |

| **Class runes** | Fateful Strike, Demonic Pact, Chaotic Aptitude (via Demon Hunter tree — see [`Runes.md`](Runes.md)) |

### The Cursed Captain — Ritual of Heresy

| | |
| --- | --- |
| **How** | Clear Unholy Cathedral on **Ritual of Heresy** |
| **Role** | Mixed |
| **Skill types** | Blast, Bomb, Projectile, Swing, Thrust |
| **Stats (base)** | −10 max HP, +5% crit chance, +20% crit damage, +15% experience |
| **Class runes** | Pirate's Rum (Versatility), Curse of the Depths, Devastating Blow (via Cursed Captain tree) |

## Per-character stained glass

Clearing Cathedral with a given character lights a **stained-glass** marker for that character next to the mode. Cosmetic / completion tracking — not a separate gear or rune unlock. Repeat per character if you want the full window.

---

## Quick tips

1. Access Cathedral after enough Void Field / curse progression (it will not show early).
2. For **Demon Hunter**, you only need **Hate**, not Heresy first.
3. For **Cursed Captain**, clear **Heresy** (harder) — bring a strong Void Field build.
4. Run rewards still drop materials / soulstones even after characters are unlocked; Endless Heresy is for challenge / grind after that.
