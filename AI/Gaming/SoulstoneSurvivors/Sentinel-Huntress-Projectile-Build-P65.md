# Sentinel — Huntress Projectile Build (Prestige 65)

Soulstone Survivors. Tuned for **prestige 65** **without Misery’s End** (not crafted / skipped). **Noxious Longbow** is still locked (prestige 70).

You have **~45 skill-tree points**. Prioritize **Nature’s Guardian**, then mount potency / cast freq / crit / move. Buy **Extended Reach** (60k) when you can — huge for Projectile. **Unconventional Start** is optional. Skip **Immovable Object** on this kite build (punishes moving).

## Why Huntress Projectile (not Misery’s End / not Noxious yet)

- **Misery’s End** is the P40 Doom bow — skippable; Doom is a weak identity vs arrow spam / Poison
- **Noxious Longbow** (P70) is the real Poison power spike — you do not have it yet
- **Huntress Bow** + **Ricochet Shot** (P50) + **Sniper Shot** (P20) is the strongest kit you can field right now: Aptitude → crit damage, Dazed → multi-crit, Ammunition → multicast spam
- Class is glass (−50 HP) but **+move / +dash / +crit** — kite, don’t tank

**Nature’s Guardian (ascension):** panthers spawn on the map. Stay near one to fill the bond gauge → **mount** (~40s): big crit / damage / cast freq / move / extra dash. Track panthers like Hound Master meat / Shaman ritual pyres.

**Playstyle:** stay at range, keep moving (or mount and zoom). Corner-camp for denser packs if you can dodge. Don’t stand still for Immovable Object.

| Role | Prefer | Solid swaps (same role) |
| --- | --- | --- |
| **Dazed / Aptitude hit-rate** | **Split Shot** | Frag Shot, Spread Shot |
| **Screen flood** | **Storm of Arrows** | Bolt Barrage (if offered), Chromatic Bolt |
| **Extra nuke / setup** (7th) | **Frag Shot** | Keep a second flood skill |

**Example final 6:** Shoot · Rain of Arrows · Ricochet Shot · Sniper Shot · Split Shot · Storm of Arrows  
**Example final 7 (Repertory):** above + Frag Shot

**Swap rules:**

- Never drop the four **cores**.
- Prefer skills that grant **Aptitude** and/or **Dazed**.
- Do not fill with Doom / Misery’s End skills.
- **Skill Mastery: Projectile** is useless on Sentinel — you already have Projectile. Use **Inclination: Projectile** instead.

### Skill priority while leveling

1. **Rain of Arrows** (Weapon Expert) + **Shoot**
2. **Ricochet Shot** — lock ASAP
3. **Sniper Shot**
4. Split Shot / Storm of Arrows / Frag Shot / Spread Shot

## Passives — take / ban

### Prioritize

1. **Crit chance → crit damage** (Aptitude + Sniper)
2. **Cast frequency** / **multicast** / Ammunition helpers
3. **Movement** + Magnetic (panthers + XP)
4. **Damage** / area
5. **Max HP** (class −50 HP — take some)
6. Dazed / Aptitude / Projectile skill-chain passives

### Soft-ban / ban

- Main-ailment **Doom** (Misery’s End temptation)
- **Armor / block** soft-ban — kite + dashes
- Don’t banish crit / Projectile / Aptitude paths

## How to play a run

1. Weapon Expert → Rain of Arrows + Shoot; lock **Ricochet** and **Sniper**.
2. Kite at range; dump arrows; Sniper for Lords when crit is online.
3. Bond **panthers** whenever they spawn — mounted windows are huge power spikes.
4. Corner-camp only if your dodge is clean (−50 HP hurts).
5. Farm **prestige 70 Noxious Longbow** for the Poison pivot; Misery’s End is optional Doom side content.
