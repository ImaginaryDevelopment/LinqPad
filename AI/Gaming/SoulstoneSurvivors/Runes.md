# Soulstone Survivors — Runes Reference

Local lookup for **slot** (Tenacity vs Versatility) and **category** (in-game filter). Use this instead of re-fetching the wiki when writing builds.

**Rules of thumb**

- Equip up to **4 Tenacity** (spend Runic Power) and **3 Versatility** (always **0** Runic Power).
- Tenacity and Versatility are separate tabs — a rune only appears in one.
- Category = the filter chips in that tab (Negative, Power, Utility, …).
- Unlock column = character skill tree or achievement; once unlocked, any character can equip it.

Source snapshot: [wiki Runes page](https://soulstone-survivors.fandom.com/wiki/Runes) (plus Skill Affinity / Inclination / Mastery from community guides — those skill-pool runes are often listed separately per skill type).

| **Skill Mastery: \<Type\>** | Skill-pool | Clear a match in under 12:00 on the class that owns that type |

**Skill-pool notes**

- **Affinity:** biases early level-ups toward that skill type.
- **Inclination:** that skill type shows up more often all run.
- **Mastery:** adds skills of that type your character would not normally have in the pool.
- There is one Affinity / Inclination / Mastery rune **per skill type** (Bomb, Earth, Fire, …). Look under Versatility; filter by skill-pool / type name if the UI offers it.
