# Myrmidon — Chant Crit Build (Prestige 84)

Soulstone Survivors. Tuned for **prestige 84** — **maximum Myrmidon power** through Epic. Full Epic kit including **Wail of the Reefs**. Primary path is **Chant of the Claws** crit + **Hymn** Devastating / Dazed via **Unexpected Arsenal**.

**P100+ note:** Legendary unlocked in update 1.4 (craft at prestige 100). Community endgame still runs **this same Chant / Hymn crit kit** — power at high OL comes from **Blessing → Fury of the Seas form** (fervor uptime + Oceanic Strike), not a different weapon board. No separate P100 guide until the Legendary’s skills are worth swapping for.

## Why Chant Crit (not Wail / not Song-first)

At P84 the Myrmidon ceiling is **multi-crit under Precision Wave + Chant stats**:

- **Chant of the Claws** gives huge **+crit damage / +cast freq** and a servant **+15% crit chance** aura — class already starts **+15% crit**
- **Incisive Strike** multiplies damage off **your crit chance** — Precision Wave makes this grotesque
- **Sanctified Throw** (**Devastating** = crits ×3) + **Holy Frenzy** (Dazed hose) from Hymn via **Unexpected Arsenal** without sitting on Hymn’s −multicast gun
- **Blessing of the Depths** trident windows: **Oceanic Strike** + crit damage / armor / cast freq / move — bank for Lords
- **Song of the Sirens** Ice / Slow is the best *thematic* alt (Hypothermia → Disarray) — see below
- **Wail of the Reefs** Earth is the P70 unlock and the **weakest** Epic — skip for peak

## Character notes

| Trait | Value |
| --- | --- |
| Max HP | +20 |
| Crit chance | +15% |
| Armor | +20 |

**Skill types:** Arcane · Ice · Holy · Earth · Thrust

**Blessing of the Depths (ascension):** kills fill a **fervor** gauge. When full, a **trident** drops — walk through it to become Blessed: temporary **Oceanic Strike** skill + **+crit damage / +armor / +cast freq / +move**. You can leave the trident on the ground until a Lord fight. Track fervor like Engineer fuel.

**Servants:** you always have a **heal Gillkin** plus a weapon-aura ally (Chant = crit chance aura). Artifact **Gillkin Servants** spawn more Cunning pets (ailment depends on weapon).

**Playstyle:** tanky ocean melee — stand in packs, fix cast freq, scoop tridents for Lords. Crit chance → 100%+ for multi-crits.

- **Skill Mastery: Arcane / Ice / Holy / Earth / Thrust** — useless (native).
- Empowering buffs (**Precision Wave**, Arcane Power) **refresh, do not stack**.

### Skill priority while leveling

1. **Incisive Strike** (Weapon Expert) + **Tidal Thrust**
2. **Precision Wave** — lock ASAP
3. **Sanctified Throw** / **Holy Frenzy** via Arsenal
4. Arcane Power

## Passives — take / ban

### Prioritize

1. **Crit chance** → **crit damage** (multi-crit + Incisive / Devastating)
2. **Cast frequency** (class −10%) / multicast
3. **Area** (Holy Frenzy clear)
4. **Magnetic** + **Movement** (tridents + XP)
5. **Blessing / Oceanic Strike** nodes when offered
6. Armor / max HP as needed (you are already tanky)
7. Form / Dazed helpers

### Soft-ban / ban

- Pure **Earth** / Wail greed
- **Slow-only** Ice greed that dilutes crit (use Ice alt instead)
- **Skill Mastery** for types you already have
- Don’t banish crit / Dazed / Form / Magnetic

## How to play a run

1. Weapon Expert → Incisive Strike; lock **Precision Wave** early.
2. Fish **Sanctified Throw** / **Holy Frenzy** via Arsenal; keep crit chance climbing.
3. Fill **fervor** → leave tridents for Lord windows when you can.
4. Lords: Precision Wave up → Incisive + Devastating Throw melt; Holy Frenzy keeps Dazed multi-crits.
5. Try **Song Ice / Slow** or on-gun **Hymn** as sidegrades; skip Wail for peak.

## Alternate: Song of the Sirens — Ice / Slow / Disarray

## Alternate: Hymn of the Depths — On-gun Holy Crit

Same skills as peak, but weapon is Hymn (Purity servant aura, −multicast). Keep Sanctified Throw + Holy Frenzy + Precision Wave + Arcane Power; pull Incisive via Arsenal if crafted Chant.

**Runes:** same Crit Tenacity + Weapon Expert · Reroll · Inclination: Holy.

Fix multicast with passives / Infused-equivalent spam (Arcane Power).

## Alternate: Wail of the Reefs — Earth (not recommended)

Abyssal Fissure · Fury of the Depths · Colossal / Form Earth skills. Weaker ceiling — only if you want the P70 toy.
