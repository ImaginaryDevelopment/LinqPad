# Shaman — Spinevine Poison Build (Prestige 35)

Soulstone Survivors. Tuned for **prestige 35**: Spinevine Poison with **Cobra Totem**, class skill tree, and **Ancestral Ritual**. No Flamelash (40) / Stone Spiral (50) / Lasher (70) yet.

For the prestige-1 starter version, see [`Shaman-Poison-Spinevine-Build-P1.md`](Shaman-Poison-Spinevine-Build-P1.md).

You have **~15 skill-tree points** (prestige − 20). Prioritize **Ancestral Ritual**, then ritual potency / max HP / multicast / damage nodes. Unlock **Savage Pact** (and Prophecy if you banish a lot) with soulstones when you can.

## What changed vs P1

| Keep | Change |
| --- | --- |
| Spinevine Whip + Poison identity | Add **Cobra Totem** to the board (Poison + **Weakness**) |
| Vine Whip · Poisonous Thorn · Pestilence | Ritual dance is now part of the loop |
| Poison passives (Venomous, Death and Decay, etc.) | Slot **Savage Pact** if unlocked (HP → crit damage) |
| Weapon Expert + Reroll Mastery | Shockwave Totem demoted — Cobra does Ancestry better for Poison |

**Do not** force a Starweaver swap just because you unlocked it. Stay Spinevine for Poison; Starweaver is a separate totem/Radiance build.

## Why still Spinevine Poison

- **Poisonous Thorn** still scales Poison with **max HP**; ritual’s +HP buff makes that stronger, not weaker
- **Cobra Totem** is the missing piece from P1: static Poison + Weakness + Ancestry + Fortitude
- **Ancestral Ritual** ghosts add real DPS and ride summon passives
- Flamelash / full totem-laser kits are later prestige pivots

## Skills (final 6) — P35 Spinevine Poison

### Core (do not swap)

| Skill | Role |
| --- | --- |
| **Vine Whip** | Pull + Poison + Ancestry |
| **Poisonous Thorn** | HP-scaling Poison (Weapon Expert) |
| **Pestilence** | Poison flood + stack-scaling damage |
| **Cobra Totem** | Poison + **Weakness** + Ancestry (prestige 20) |

With **Improved Repertory**, that is four cores + three flex in a 7-skill bar. Without it, drop the weakest flex and keep all four cores if you can; if forced to cut one core, cut **Pestilence** only when you have **Purging Slam** / **Contagion** as detonate — otherwise never cut Cobra / Whip / Thorn.

### Flex slots (2–3)

Skills marked with † need **Skill Mastery: Nature** (foreign Nature — not in Shaman’s native pool otherwise).

| Role | Prefer | Solid swaps (same role) |
| --- | --- | --- |
| **Sustained AoE applicator** | **Acid Rain** | Poison Cloud, Poison Puddle |
| **Extra stacks / detonate** | **Corrosion†** if Mastery: Nature is on; else **Poison Bolt** | Contagion†, Purging Slam†, Poison Puddle, Poison Cloud |
| **Ancestry / crit setup** (if you have a 7th) | **Bull Charge** | Shockwave Totem, Light Beam, Arcane Power |

† = requires **Skill Mastery: Nature** on your Versatility bar.

**Corrosion vs Poison Bolt:** not the same tier. **Corrosion** is the better flex when Mastery: Nature is equipped (fast aura stacks + delayed burst). **Poison Bolt** is the best *native* filler when you do not have Mastery — do not skip Corrosion hoping for Bolt if Corrosion is offered.

**Example final 6:** Vine Whip · Poisonous Thorn · Pestilence · Cobra Totem · Acid Rain · Corrosion  
**Example final 7 (Repertory):** above + Bull Charge *or* Poison Bolt

**Swap rules:**

- **Cobra Totem** is now core — do not swap it for Shockwave Totem.
- **Bull Charge** is nice Ancestry/Dazed/Purity, not required for Poison.
- Prefer **Corrosion** / **Purging Slam** over a second puddle if Mastery: Nature is on.
- Never sit waiting for Flamelash / Stone Spiral skills.

### Skill priority while leveling

1. **Poisonous Thorn** (Weapon Expert) + **Vine Whip**
2. **Cobra Totem** — lock ASAP
3. **Pestilence**
4. Acid Rain / Corrosion / Poison Bolt
5. Bull Charge only if you still have a free slot and want more Ancestry

## Passives — take / ban

### Prioritize

1. **Max HP** (Thorn + Savage Pact + ritual)
2. **Poison** — Venomous, Corrosive, **Death and Decay**, Infected Wounds
3. **Multicast** / cast frequency / area
4. **Movement** + Magnetic (ritual orbs + XP)
5. Crit chance → crit damage
6. Summon / totem count or damage if offered

### Soft-ban / ban

- Main-ailment **Bleed / Fire / Doom** passives
- Don’t banish Poison / Nature / max HP / ritual-adjacent offers

## How to play a run

1. Weapon Expert → Thorn + Vine Whip; lock **Cobra Totem** early.
2. Whip packs into Cobras; Weakness makes every Poison tick hurt more.
3. When the pyre spawns, **finish the dance** — ghosts + HP buff are a huge chunk of your power budget.
4. Lords: Cobras down, stack Poison, Pestilence / Purging Slam / Contagion to finish.
5. Farm toward **prestige 40** Flamelash only if you want Fire; otherwise push **50 / 70** for Stone Spiral / Lasher totem toys. Poison Spinevine stays valid the whole way.
