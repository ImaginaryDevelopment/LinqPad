# Elementalist — Nature Poison Build (Prestige 77)

Soulstone Survivors. Tuned for **prestige 77**: **Scepter of Nature** just unlocked (P70). This is the strongest Elementalist kit at this prestige — **Poison detonate**, not Thunder crit or Flame Burn.

You have **~57 skill-tree points**. Prioritize **Elemental Overload**, then orb drop rate / overload potency / cast freq / multicast / area / max HP. Buy Elementalist runes: **Synchrony** (2), **Elemental Flow** (2), **Endless Refill** (0).

## Why Nature Poison (not Thunder / not Flame)

- **Contaminated Cut** detonates **Poison** for multiplied instant damage — Elementalist’s best dedicated kill skill
- Weapon stats are perfect for ailment spam: **+damage / +cast freq / +multicast**, −crit (you do not need crit)
- Poison spreads between enemies → clear scales for free
- **Scepter of Flame** + Heat Explosion is the other top option — slightly more setup; Poison is cleaner at P77
- Mixing “all elements” dilutes passives (Elementalist orb drops pollute the pool) — **focus Nature / Poison** and banish off-ailments

**Skill types:** Ice · Nature · Fire · Electric · Earth

**Elemental Overload (ascension):** kills drop elemental orbs (~10%). Collect **3** → fire a burst based on which orbs you grabbed. Pick them up while kiting — free damage. Do not egg-hunt perfect combos; scoop what is near.

**Playstyle:** glass caster (−HP, −cast freq). Fix cast freq with passives / weapon. Spam Poison applicators, **Contaminated Cut** Lords when stacks are thick. Ban off-element passives hard — Overload will keep offering Burn/Doom/etc. junk.

## Skills (final 6–7) — Nature Poison

### Core (do not swap)

| Skill | Role |
| --- | --- |
| **Contaminated Cut** | Poison detonate / Lord kill |
| **Outbreak** | Poison flood (Weapon Expert) |
| **Pestilence** | Chain Poison + scales with stacks |
| **Poison Bolt** *or* **Venomous Strike** | Fast applicator |

Prefer **Venomous Strike** if you want Finesse / multicast; prefer **Poison Bolt** for simpler frontal spam.

### Flex slots (2–3)

| Role | Prefer | Solid swaps (same role) |
| --- | --- | --- |
| **Weakness / hit-rate** | **Festering Strike**† | Acid Rain, Poison Cloud |
| **Screen flood** | **Bladestorm**† | Poison Cloud, Acid Rain |
| **Extra Poison** (7th) | **Acid Rain** | Corrosion, Pestilence if not core |

† **Bladestorm / Venomous Strike / Festering Strike** need **Skill Mastery: Swing** — Elementalist lacks Swing. Pair Mastery: Swing with this path.

**Example final 6:** Contaminated Cut · Outbreak · Pestilence · Venomous Strike · Festering Strike · Bladestorm  
**Example final 7 (Repertory):** above + Acid Rain / Poison Bolt

**Swap rules:**

- Never drop **Contaminated Cut** or **Outbreak**.
- Prefer skills that apply **Poison** and/or **Weakness**.
- Aim Contaminated Cut at **Lords** (small AoE is a feature — do not wipe trash stacks by accident if you can help it).
- **Skill Mastery: Nature / Fire / Ice / Electric / Earth** — useless (native). Use **Inclination: Nature** only if unlocked elsewhere (Beastmaster / Shaman).
- Do not fill with Tornado, Lava Shield, or Heat Explosion on this path.

### Skill priority while leveling

1. **Outbreak** (Weapon Expert) + **Contaminated Cut**
2. **Pestilence**
3. Venomous Strike / Poison Bolt / Festering Strike
4. Bladestorm (once Venomous passive is online) / Acid Rain

## Passives — take / ban

### Prioritize

1. **Venomous** (multi) → **Corrosive** → **Death and Decay** / Infected Wounds
2. **Cast frequency** / **multicast** (class −10% cast freq — fix early)
3. **Movement** + **Magnetic** (orbs + XP)
4. **Damage** / area
5. Some **max HP** (class −20)
6. Weakness / Poison skill-chain

### Hard-ban / ban

- Main-ailment **Burn / Doom / Bleed / Slow** greed — Overload already floods these offers; banish aggressively
- **Poisonous Blood**-style converters that dilute Poison into something Contaminated Cut does not detonate
- Crit greed (weapon −crit; not your win condition)
- **Skill Mastery** for types you already have

## How to play a run

1. Weapon Expert → Outbreak + Contaminated Cut; lock **Pestilence**.
2. Stack Poison on packs; **Cut** Lords when stacks are high.
3. Scoop **elemental orbs** when safe — free Overload bursts.
4. Once Venomous is online, Bladestorm becomes a Poison hose.
5. Try **Flame Heat Explosion** or **Thunder crit** as sidegrades; Frost is optional fun only.
