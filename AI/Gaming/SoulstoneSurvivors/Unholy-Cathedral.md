# Unholy Cathedral

Soulstone Survivors general reference for the **Unholy Cathedral** game mode (Update 12, Aug 2024). Covers how a run works, cycle mechanics, difficulties, and permanent unlocks.

Also see character-specific Cathedral tips (e.g. Monkey King cycle combos in [`MonkeyKing-Bleed-Boomstick-Build-P57.md`](MonkeyKing-Bleed-Boomstick-Build-P57.md)).

---

## What it is

A separate mode from Void Fields / Titan Hunt. Compact arenas, short cycles, mixed material farming, and a unique final boss. You pick a **Ritual** difficulty, then play **four combat cycles** back-to-back. After cycle 4 you fight **Mh'thaeus, the Heretic**. Clear him to finish the run and collect rewards.

No manual curse setup like Void Fields — difficulty is the Ritual tier (and Endless on Heresy after unlocks).

---

## Run flow (4 cycles)

```
Enter Ritual difficulty
    ↓
Cycle 1 — kill / objectives → level → pick skills & passives
    ↓  (actives/passives from this cycle are stripped; Unholy Power kept)
Pick Unholy Power → next cycle skill pool
    ↓
Cycle 2 — same pattern
    ↓
Cycle 3 — same pattern
    ↓
Cycle 4 — same pattern (these actives also carry into the boss)
    ↓
Boss: Mh'thaeus, the Heretic
    ↓
Rewards (materials, soulstones, etc.)
```

### Per cycle

1. Fight escalating packs / lords in the Cathedral map (tight space).
2. Level up by kills like other modes — choose **active skills** and **passives** from offers.
3. Finish the cycle’s objectives / clear.
4. **Between cycles:**
   - Your **active skills and level-up passives from that cycle are stripped** (you do not keep a Void Field–style permanent 6-skill board across the whole run).
   - You choose an **Unholy Power** (Special rarity stat boost). These **persist for the rest of the run** and stack.
   - Skills you already **selected** earlier are **locked out of the pool for later cycles** (you will not see them again that run).

### Cycle 4 + boss

Cycle 4’s active set is the one you take into **Mh'thaeus**. Plan so your strongest detonate / boss tools are still available for cycle 4, not burned in cycle 1–2.

## Core mechanics

| Mechanic | What it means |
| --- | --- |
| **4 cycles** | Four short runs chained in one Cathedral attempt |
| **Skill lockout** | Once you pick an active in any cycle, it is removed from later cycle offers for that run |
| **Strip between cycles** | Actives + normal passives reset when the cycle ends; you rebuild each cycle |
| **Unholy Powers** | Special powers picked after a cycle; **keep** across cycles (main permanent power within the run) |
| **Runes** | Equipped before the run as usual; they apply the whole Cathedral attempt |
| **Weapon / character** | Chosen at start; Twilight Harmony / other ascensions still work |
| **Rerolls / locks / banishes** | Still useful — save rerolls for cycle 4 / boss setup when possible |
| **Daily / repeat** | Mode is meant for repeated clears; rewards materials even after unlocks |

### Skill-pool strategy (important)

Because picked skills never return:

- Early cycles: burn **weaker / filler** actives so the pool thins.
- Late cycles (especially **4**): leave **Shrapnel Bomb, Expansive Throw, Contagion-type detonates**, strong AoE, etc. still available.
- Do **not** “save” a god skill for a future offer — if you skip it now, it may still appear later, but if you **take** it early it’s gone for cycle 4.

Community note: some inclination / pool-expanding runes (e.g. Omnipotent) make the pool larger and harder to control; Reroll Mastery / Endless Refill help you shape offers without depending on one fixed 6-skill build.

## Unholy Powers

Granted after completing a cycle. Special-rarity **stat** upgrades (not normal level-up passives). They remain for the rest of the run.

Examples of names seen on the wiki (Touch of …):

- Touch of Sinfulness
- Touch of Vulgarity
- Touch of Immorality
- Touch of Wrath
- (and related Touch-of-* variants)

Prefer damage, cast frequency, area, and movement when offered — same priorities as a short Void Field clear. You get several across a full 4-cycle clear, so they are your main “carry” stats while actives keep rotating.

## Ritual difficulties

| Ritual | Rough tier | Notes |
| --- | --- | --- |
| **Ritual of Sin** | Easiest | First clear → achievement |
| **Ritual of Hate** | Mid | Unlock **Demon Hunter** |
| **Ritual of Heresy** | Hardest | Unlock **Cursed Captain**; unlocks **Endless** after all three base rituals cleared |

### Heresy Endless (after all three rituals)

Heresy gains +1 / +2 / … tiers. Enemy scaling examples from the wiki:

| Tier | Enemy HP | Enemy dmg | Enemy AS | Enemy move | Lords extra HP |
| --- | --- | --- | --- | --- | --- |
| Heresy +0 / +1 | +80% | +20% | +20% | +20% | +700% |
| Heresy +2 | +100% | +30% | +30% | +30% | +800% |

(Higher +N continues escalating; treat as optional challenge / grind.)

**Naming caveat:** UI / achievement text sometimes confuses “Sin” and “Heresy.” Unlock mapping below is from character pages — trust **Hate → Demon Hunter**, **Heresy → Cursed Captain**.

## Permanent unlocks

| Clear | Unlock |
| --- | --- |
| **Ritual of Sin** | Achievement: **The Purge – Ritual of Sin** |
| **Ritual of Hate** | Character: **The Demon Hunter** |
| **Ritual of Heresy** | Character: **The Cursed Captain** |
| All three rituals once | **Ritual of Heresy Endless** |

### Demon Hunter (Hate)

- Role: Ranged · Chaos / Shadow / Projectile / Bomb / Blast  
- Stats: −10 HP, +15% damage, +10% cast freq, −5% area  
- Ascension: Demonic Binding  
- Class runes: Fateful Strike, Demonic Pact, Chaotic Aptitude → [`Runes.md`](Runes.md)

### Cursed Captain (Heresy)

- Role: Mixed · Blast / Bomb / Projectile / Swing / Thrust  
- Stats: −10 HP, +5% crit chance, +20% crit damage, +15% experience  
- Class runes: Pirate's Rum, Curse of the Depths, Devastating Blow → [`Runes.md`](Runes.md)

### Stained glass

Clearing with a character lights a **stained-glass** icon for that character by the mode. Cosmetic / completion tracking only.

## Rewards

- Materials and soulstones (good for multi-resource farming in short sessions)
- Rare / Special upgrades as part of clears
- Permanent unlocks above on first clears of each Ritual

Exact drop tables change with patches; treat Cathedral as a fast material + unlock mode, not the main prestige grind (XP / build depth is intentionally shorter than Void Fields).

---

## Practical tips

1. Unlock access by progressing Void Field curses until Cathedral appears.
2. Equip **flexible** runes (ailment / crit / reroll) — you will not keep one skill board.
3. **Burn filler skills** in cycles 1–2; **keep detonates** for cycle 4 + Mh'thaeus.
4. Stack Unholy Powers every cycle break — that is your lasting power.
5. Save rerolls for cycle 4 / boss actives when you can.
6. Stained glass is optional; characters/achievements are the must-clears.
