## Why Spinevine Poison

At P1 you only have Spinevine:

- **Vine Whip** pulls packs, applies **Poison**, stacks **Ancestry** (free supporting totems)
- **Poisonous Thorn** applies Poison that **scales with max HP** — your class identity
- Native **Nature** pool (Pestilence, Acid Rain, bolts/puddles) floods stacks
- Class already has **+15 max HP** and **+10% crit** — lean into HP + Poison, not glass kite

Goal: stack Poison + Ancestry until prestige 5–20 unlocks land.

**Playstyle:** mid-range whip. Fix move speed with passives. Vine Whip clusters enemies; dump Poison into the clump. Ancestry totems add free DPS while you kite.

**Ancestry:** skills that grant Ancestry build stacks. Casting a skill spends Ancestry to summon a **static totem** (up to **7**). Keep Ancestry skills on the board so totems keep spawning.

**Ascension (later):** Ancestral Ritual (skill tree after prestige 20) — dance the pyre orbs for a big HP/damage buff + ghost shaman minions. Not part of this P1 kit.

You do **not** have Bull Charge / Cobra Totem / Ancestral Empowerment. Fill from native Nature / Arcane / Fire / Holy / Earth offers:

### Core (do not swap)

| Skill | Role |

### Flex slots (3) — pick from these roles

| Role | Prefer | Solid swaps (same role) |
| --- | --- | --- |
| **Sustained AoE applicator** | **Acid Rain** | Poison Cloud, Poison Puddle |
| **Extra stacks / hit-rate** | **Poison Bolt** | Poison Puddle, Poison Cloud |
| **Ancestry / setup / detonate** | **Shockwave Totem** | Corrosion*, Contagion*, Light Beam (Brittle/crit setup), Arcane Power (multicast) |

\* **Corrosion** / **Contagion** / **Purging Slam** need **Skill Mastery: Nature** (foreign Nature). Worth it if unlocked on another character.

**Example final 6:** Vine Whip · Poisonous Thorn · Pestilence · Acid Rain · Poison Bolt · Shockwave Totem

**Swap rules:**

- Never drop the three **core** skills for a flex pick.
- Within a flex role, listed skills are interchangeable.
- Prefer **Shockwave Totem** early — Ancestry + Dazed (helps crit / Infected Wounds).
- Prefer **Corrosion** over a second puddle/cloud if Mastery: Nature is on.
- **Purging Slam** (Mastery: Nature) is a strong Lord detonate if offered — can replace Pestilence’s “kill” role in a flex slot, but still keep Pestilence if you can (Improved Repertory helps).

**Skip / low priority:** sitting on empty slots for Bull Charge / Cobra Totem; pure Fire that dilutes Poison; skills with no Poison / Ancestry / Weakness value.

### Skill priority while leveling

**“Lock early”** = take immediately and keep for the run.

1. **Poisonous Thorn** (Weapon Expert) + **Vine Whip** — core
2. **Pestilence** — core; lock the moment it appears
3. Fill flex: **Acid Rain** (or Cloud/Puddle), then **Poison Bolt**
4. Last flex: Shockwave Totem / Corrosion / Contagion / Light Beam / Arcane Power

## Passives — take / ban

### Prioritize

1. **Max HP** — offense for Poisonous Thorn / Fortitude-style scaling, not just defense
2. **Poison** power, duration, application (**Venomous**, Corrosive, Infected Wounds)
3. **Movement speed** (class + weapon are slow)
4. **Multicast** / **cast frequency** / **area**
5. **Crit chance → crit damage** (Infected Wounds loves crit)
6. **Magnetic**
7. Some **armor** is fine here — you are tankier than glass classes

### Soft-ban / ban

- Passives that force **Bleed**, **Fire**, or **Doom** as the main ailment
- Don’t banish Poison / Nature / Ancestry / max HP paths

## How to play a run

1. Weapon Expert on → Poisonous Thorn from the start with Vine Whip.
2. Whip packs into a clump; hose Poison; let Ancestry totems spawn behind you.
3. Pestilence / Acid Rain should never leave the board once locked.
4. Lords: stack Poison hard, then Pestilence / Contagion / Purging Slam if you have them; keep moving (−10% move hurts if you stand still).
5. Farm prestige: lower–mid curses are fine — goal is **prestige 5 → 10 → 20**, not max curse.
