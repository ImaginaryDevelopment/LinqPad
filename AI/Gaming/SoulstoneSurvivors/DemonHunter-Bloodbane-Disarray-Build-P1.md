## Why Bloodbane Disarray

At P1 you only have Bloodbane:

- **Uncontrolled Arrows** + **Madness Shot** spam **Disarray** / **Chaotic** and flood the screen
- Disarray adds variable extra damage; Chaotic procs cast other skills → more arrows
- Glass-cannon ranged: −10 HP, +15% damage, +10% cast freq, −5% area — **kite**, don’t tank

Goal: cast frequency + multicast + crit + Disarray / Chaotic synergies until prestige 5–20 unlocks land.

| **Reroll Mastery** | Versatility | Utility | Shape early skills |
| **Unexpected Arsenal** *or* **Endless Refill** | Versatility | General / Utility | See note below |

**Do not take Skill Mastery: Projectile on Demon Hunter.** Skill Mastery only adds skills of a type your character **does not** already have. DH’s native types already include **Projectile** (and Chaos / Shadow / Bomb / Blast), so Mastery: Projectile only offers *foreign* projectiles from other classes — not Weakening Shot, Explosive Shot, Storm of Arrows, or Chromatic Bolt. Those are already in your normal level-up pool without any Mastery rune.

**Skill Inclination / Affinity do help** — unlike Mastery. They bias how often a **native** type shows up; they do not add foreign skills.

| Rune | Effect | Worth at P1? |
| --- | --- | --- |
| **Skill Inclination: Chaos** | Chaos skills appear more often | Yes if unlocked (Chaoswalker prestige 60). Pushes Chaotic / Disarray offers |
| **Skill Inclination: Projectile** | Projectile skills appear more often | Yes if unlocked — more arrows sooner |
| **Skill Affinity: Chaos / Projectile** | Early levels favor that type | Nice if available; weaker than Inclination over a full run |
| DH’s own Chaos Affinity / Inclination | DH prestige 30 / 60 | Not available yet at P1 |

Priority still: **Weapon Expert + Reroll Mastery** first. Inclination is a solid third Versatility if you have Chaos or Projectile; skip if your only Inclination is an off-theme type (Earth, Ice, etc.).

Steam/YekPeak DH runes are all Tenacity (Chaos + Reach + Divine Legacy) plus whatever Versatility you like for consistency — **Weapon Expert + Reroll Mastery** are the important two. Third slot flex:

| Option | When |
| --- | --- |
| **Skill Inclination: Chaos** or **Projectile** | If unlocked on another character — biases native Disarray / arrow offers |
| **Unexpected Arsenal** | Spellblade unlocked — more unique weapon skills in pool |
| **Endless Refill** | Elementalist unlocked — rerolls/locks on portal (great for prestige farming) |
| **Skill Mastery: \<foreign type\>** | Only if you *want* off-type skills (e.g. Holy / Nature / Swing). Not needed for this Disarray arrow build |
| Leave empty / swap later | Fine at P1 — two Utility runes are enough |

## Passives — take / ban

### Prioritize

1. **Cast frequency**, **multicast**, **crit chance → crit damage**
2. **Disarray** / **Chaotic** synergies and “on apply X also apply Y” chains
3. **Damage**, **area** (offset −5%)
4. **Movement speed** + use dashes
5. **Magnetic**
6. Some **max HP** (class −10 HP)

### Soft-ban / ban

- **Armor / block** — soft-ban; kite instead (same logic as other glass builds)
- Passives that force **Poison** as your main identity (optional Bleed is fine if you go Shrapnel)
- Don’t banish Disarray / Chaotic / crit paths

## How to play a run

1. Weapon Expert on → Madness Shot from the start.
2. Kite at range; Uncontrolled Arrows + Madness Shot should never leave the board.
3. Stack Disarray; Weakening Shot makes hits hurt more.
4. Lords: keep moving, dump multicast arrow spam; don’t stand in telegraphs (−10 HP hurts).
5. Farm prestige: lower–mid curses are fine — goal is **prestige 5 → 10 → 20**, not max curse.
