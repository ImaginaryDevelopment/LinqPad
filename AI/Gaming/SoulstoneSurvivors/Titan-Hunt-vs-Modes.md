# Titan Hunt vs Unholy Cathedral vs Void Fields

Soulstone Survivors mode comparison. Use this when choosing what to farm / push next. Deep Cathedral mechanics: [`Unholy-Cathedral.md`](Unholy-Cathedral.md).

---

## One-line jobs

| Mode | Job |
| --- | --- |
| **Void Fields** | Core loop — curses, rune unlocks, Overlord / Endless portals, most prestige / build depth |
| **Unholy Cathedral** | Short sessions — skill-lockout puzzle, Mh'thaeus, Ritual unlocks (Demon Hunter / Cursed Captain), mixed materials |
| **Titan Hunt** | Boss-hunt climb — Titans → Netherworld → Corrupted Void Hunter / Void King; Shaman + sigil characters; Titanic / Corrupted / Void Powers |

---

## Titan Hunt — what it is

Pick a **Titan** (themed map) → clear **tasks** for **Void Fragments** (15 unlocks the arena) → kill the Titan → spend **Titan Blood** on a **Titanic Power** (run-long passive). After **4 Titan Blood**, open the **Netherworld** portal → **Corrupted Void Hunter** → (on Sigil of the Void) **Void King**.

**Sigils** are the difficulty ladder: Corruption → Vileness → Wickedness → Hate → Void, then Endless (+1 cycles) like Cathedral Heresy Endless. Enemy HP / damage / elite / boss HP and rewards scale hard; each **Titan slain in the same run** also stacks massive enemy HP (and ailment resist).

**Exclusive unlocks:** Shaman (clear Titan Hunt), Machinist (Sigil of Vileness — [`Machinist-Coremelter-Burn-Build-P60.md`](Machinist-Coremelter-Burn-Build-P60.md)), Samurai (Sigil of Wickedness). Not available from Cathedral / Void Fields.

## Pros of Titan Hunt (vs Cathedral / Void Fields)

| Pro | vs Cathedral | vs Void Fields |
| --- | --- | --- |
| **Unique unlocks** | Only way to get Shaman / Machinist / Samurai | Same — those characters are Titan-only |
| **Boss-fight fantasy** | Multi-phase Titans + Void King vs one Mh'thaeus | More “hunt a named boss” than wave quotas + Lords |
| **Power stacking in-run** | Titanic / Corrupted / Void Powers are chunky, build-aligned passives | Closer to curse scaling than to Cathedral’s Touch-of-* Unholy Powers |
| **You keep your build** | Full skill board for the whole run (no strip / lockout) | Same as Void Fields — deepen one kit |
| **Sigil + Endless climb** | Parallel endgame ladder to Heresy Endless; high +N = big materials / prestige / soulstones | Different ladder than curse VII / Overlord |
| **Themed maps + task variety** | Larger maps than Cathedral’s tight arena | Tasks (white→purple) instead of only kill quotas |

---

## Cons of Titan Hunt (vs Cathedral / Void Fields)

| Con | vs Cathedral | vs Void Fields |
| --- | --- | --- |
| **Session length** | Longer than 4 short Cathedral cycles | Can feel longer / more backtracky than a focused Void clear |
| **Boss HP wall** | Titans / Void King scale brutally with sigil + Titans-slain | Worse than normal Void Lords for underbuilt kits |
| **After unlocks, thin reasons** | Cathedral still has stained glass + Heresy Endless grind; Titan’s “must-do” ends at Shaman / sigil chars for many players | Void Fields still gates most runes, curses, Overlord, daily progression |
| **Ailment resist spiral** | Each Titan slain in-run boosts enemy status resist — DoT kits get punished late | Void Fields curse kit is more predictable |
| **Less flexible farming** | Cathedral is better for mixed materials in 3–5 min chunks | Overlord / high-curse Void usually beats Titan for boss parts / efficient prestige once unlocked |
| **Skill expression differs** | No Cathedral pool-management puzzle | No curse loadout theorycrafting |

## Unholy Cathedral — when to prefer it

**Pick Cathedral when you want:**

- Fast clears / short sessions
- Demon Hunter (Hate) / Cursed Captain (Heresy) unlocks
- Practice adapting without a fixed 6-skill board
- Mixed material drops without committing to a long Void / Titan run

**Avoid as your main grind when you want:** deep prestige XP, rune achievements, Overlord, or Titan-only characters.

See recommended Cathedral classes in [`Unholy-Cathedral.md`](Unholy-Cathedral.md).

---

## Void Fields — when to prefer it

**Pick Void Fields when you want:**

- Primary progression (curses, character prestige, most rune unlocks)
- Build depth — one kit for the whole match
- Overlord / Endless portals (fast clears)
- Predictable farming loops you already optimize

**Weaker when you want:** Titan unlocks, Cathedral Ritual characters, or a short “one more run” between other tasks.

## Decision cheat sheet

```
Need Shaman / Machinist / Samurai / Void King?     → Titan Hunt
Need Demon Hunter / Cursed Captain / stained glass? → Unholy Cathedral
Need curses, runes, Overlord, main prestige grind? → Void Fields

Short session + materials?     → Cathedral (or quick Void)
Boss-hunt + big in-run powers? → Titan Hunt
Best overall efficiency long-term? → Void Fields / Overlord (then Titan/Cathedral for unlocks)
```

---

## Practical notes

1. **Do Titan Hunt** until Shaman + sigil characters are unlocked; push Endless only if you enjoy the climb / want the rewards at your +N plateau.
2. **Do Cathedral** for Ritual unlocks and when you have 10–15 minutes — bring flexible classes (Pyromancer, Assassin, Monkey King, Engineer, Elementalist).
3. **Live in Void Fields** for account power. Titan and Cathedral are satellites around that core.
4. Titanic Powers favor builds that match the Titan’s themes (Poison, Bleed, Prowess, etc.) — Synergetic helps chain-effect powers.
