Soulstone Survivors. Tuned for **prestige 70**: full weapon kit including **Vulcan’s Impaler**. Primary path is **Jupiter’s Reach** Electric / Dazed / infantry.

## Why Jupiter Electric (not Light Spear / not Vulcan-first)

- **Jupiter’s Reach** + **Summon Infantry** is the strongest Legionnaire kit: Dazed → multi-crit, infantry + Centurionate army clear the map
- **Light Spear** Shield Bash (armor scaling) is the tank fantasy — solid, but slower clear than Electric
- **Fang** Poison is great for long Endless / ailment scaling
- **Vulcan’s Impaler** is the P70 unlock — playable Burn, but weapon skills are weaker than Jupiter’s; treat as a sidegrade until you like Fire spam
- Class is a real tank (+HP, +armor, flat DR) — you can stand in packs while infantry works

**Skill types:** Chaos · Nature · Fire · Electric · Thrust

**Centurionate (ascension):** six wounded legionnaires spawn on the map. Stand near each ~1s to rally them. After all six: **Centurion** (~50s) — big damage / **+80% armor** / +area, plus a skyfall army (≈12 legionnaires). Track wounded soldiers like Engineer fuel / Shaman pyres.

**Playstyle:** rally early, keep infantry up, feed Dazed, crit Lords. You do **not** need glass-cannon kiting — still dodge telegraphs, but armor passives are fine.

- Prefer **Dazed** / Electrified / crit enablers.
- **Skill Mastery: Electric / Thrust / Nature / Fire / Chaos** — useless (native types). Mastery only for types you **lack** (e.g. Swing on Vulcan Burn).
- **Intimidating Shout** — skip unless you want the Weakness aura.

## Passives — take / ban

### Prioritize

1. **Crit chance → crit damage** (Dazed multi-crit)
2. **Cast frequency** / multicast
3. **Movement** + Magnetic (wounded soldiers + XP)
4. Electrified / Dazed / Electric skill-chain
5. Summon damage / duration (infantry + Centurion)
6. Armor / max HP only as needed (you start tanky; Centurion +80% armor)

### Soft-ban / ban

- Don’t banish Electric / Dazed / crit paths
- Pure Doom / Poison greed soft-bans this path (use Fang alt instead)
- **Skill Mastery** for types you already have

## How to play a run

1. Weapon Expert → Infantry + Jupiter’s Spear; lock **Lightning Surge**.
2. Rally all six **wounded legionnaires** ASAP → Centurion windows are huge.
3. Keep Infantry refreshed; circle Lords while Dazed stacks for crits.
4. Pick up artifact Catapult charges when Jupiter is fully upgraded.
5. Try **Vulcan Burn** or **Fang Poison** as sidegrades; Light Spear if you want armor-scaling Shield Bash.
