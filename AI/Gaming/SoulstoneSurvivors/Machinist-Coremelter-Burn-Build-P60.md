# Machinist — Coremelter Burn Build (Prestige 60)

Soulstone Survivors. Tuned for **prestige 60**: **Coremelter GTX Ti** + full unique kit (**Ice Resonance**). Primary path is **Burn detonate** — stack Burn, delete Lords with **Ember Discharge**, cash **Machine Spirit / Prismatic Cannon** windows. **Electrotaser RX** is prestige **70** — ignore Lightning Coil peak guides for now.

Unlocked via **Sigil of Vileness** (Titan Hunt). See [`Titan-Hunt-vs-Modes.md`](Titan-Hunt-vs-Modes.md).

## Why Coremelter Burn (not M249 / not Soulcore / not Electrotaser)

- **Electrotaser RX** is P70 — best Electric crit stats, but you do not have it yet
- **Coremelter** gives a true Burn kill skill: **Ember Discharge** spends Burn stacks for **200%** instant damage (same fantasy as Contagion / Heat Explosion)
- **Flame Syphon** pulls packs into Burn + **Weakness** — amplifies ticks and sets up Discharge
- **Machine Spirit** Prismatic Cannon dumps Fragility / Shattered / Weakness / Dazed / Brittle — free setup for any path; Burn still clears fastest at P60
- Soulcore Brittle and M249 Ammo are real alts — see below
- High Voltage is a strong **Devastating** flex even on Burn boards

### Flex slots (2–3)

| Role | Prefer | Solid swaps (same role) |
| --- | --- | --- |
| **Burn flood / clear** | **Firestorm** *or* **Combustion** | Flamethrower, Flame Wave, Meteor |
| **Multicast engine** | **Arcane Power** | — |
| **Extra Burn / poke** (7th) | **High Voltage** | Fire Bolt, Ice Resonance, Fiery Blades |

**Example final 6:** Blazing Ray · Ember Discharge · Flame Syphon · Firestorm · Combustion · Arcane Power  
**Example final 7 (Repertory):** above + High Voltage / Fire Bolt

**Swap rules:**

- Never drop **Blazing Ray**, **Ember Discharge**, or **Flame Syphon**.
- Prefer skills that apply **Burn** and/or **Weakness**.
- Dump Ember Discharge when Lords are heavily Burned — frontal cone, aim at the boss.
- **Skill Mastery: Arcane / Ice / Fire / Electric / Blast** — useless (native). Use **Inclination: Fire** if that is your P60 unlock.
- Do not wait for Electrotaser skills — they will not appear until P70 / craft.

### Skill priority while leveling

1. **Ember Discharge** (Weapon Expert) + **Blazing Ray**
2. **Flame Syphon**
3. Firestorm / Combustion / Flamethrower
4. **Arcane Power** + High Voltage / Fire Bolt

## Passives — take / ban

### Prioritize

1. **Burn** chain — Fiery Amplification / Spontaneous Combustion / Ignition Point / Incinerate / Intense Fire
2. **Movement** (class −10%)
3. **Cast frequency** / **multicast** / **area**
4. **Damage**
5. Some **max HP** / armor (you are already tanky — still help on high curse)
6. Fire / Magical skill-chain upgrades
7. **Machine Spirit** nodes when offered (cannon damage / duration)

### Soft-ban / ban

- Main-ailment **Poison / Bleed / Doom** greed
- Mixing “all elements” forever — Prismatic already sprays debuffs; keep **Burn** as the spend resource
- **Skill Mastery** for types you already have

## How to play a run

1. Weapon Expert → Ember Discharge + Blazing Ray; lock **Flame Syphon**.
2. Pull packs with Syphon; stack Burn; **Ember Discharge** Lords when thick.
3. Mine **Energy Crystals** → bank **Prismatic Cannon** for Lord waves (Fragility / Weakness / etc. free).
4. Fix move early — you are a brick with a flamethrower.
5. Try **High Voltage Electric**, **M249 Ammo**, or **Soulcore Brittle** as sidegrades; Electrotaser after P70.
