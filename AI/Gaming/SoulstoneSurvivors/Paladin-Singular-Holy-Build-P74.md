## Why Singular Holy (not Dawnbreaker / not Warhammer)

- **Templar’s Verdict** has **Devastating** (crits deal **×3** instead of ×2) — Paladin’s real kill skill
- **Beacon of Light** ×3 stacks **Exposed** every 0.5s + **Purity** (damage wave + heal when consumed)
- **Harbinger** gives the **crit damage / multicast** stats Sacred Warhammer refuses to give; dump its weak starter skills via Unconventional Start
- **Inclination: Holy** (P60) finally feeds duplicate Beacons / Verdicts
- **Dawnbreaker Slam** is the P70 toy — solid Prowess path, weaker ceiling than Devastating Holy crit + Purity heal
- Class is a tank (+HP, +armor, +heal, −move, −crit) — fix **move** and **crit chance** early

**Skill types:** Arcane · Electric · Holy · Swing · Slam

**Divine Inspiration (ascension):** yellow **holy light** pillars spawn. Stand in them as they charge (~5 fills the gauge). Missed pillars leave a collectible sphere. Full gauge → **Vengeful**: +20% crit chance, +25% crit damage, +55% damage, +50% armor, +15% cast freq, +40% move, +5% area, huge pushback resist. Track lights like Shaman pyres / Chaoswalker essences.

**Purity:** stack via Holy skills → at threshold, consume for a light wave (damage + heal if enough enemies hit). This build’s sustain engine.

**Playstyle:** tanky but slow — take move passives. Stack crit to 100%+. Beacons clear / soften; Verdicts delete. Cash Vengeful windows on Lords.

## Passives — take / ban

### Prioritize

1. **Crit chance → 100%+**, then **crit damage** (Verdict Devastating)
2. **Movement** (class −10%) + **Magnetic** (holy lights + XP)
3. **Area** (Beacon / Verdict clear)
4. **Cast frequency** / **multicast**
5. **Armor / max HP** (offset Demonic Pact)
6. Holy / Aura / Area skill-chain group upgrades

### Soft-ban / ban

- Main-ailment **Poison / Fire / Doom / Bleed** greed
- Pure armor stacking *before* crit is online
- **Skill Mastery** for types you already have
- Leviathan (move tax)

## How to play a run

1. Unconventional Start → reroll for **Beacon**; lock **Verdict**; duplicate both.
2. Stand in **holy light** pillars → bank **Vengeful** for Lords.
3. Beacons soften (Exposed); Verdicts crit-delete; Purity heals between waves.
4. Fix move early — you are a brick with wings when Vengeful is up.
5. Try **Dawnbreaker Slam** or Harbinger **Electric** as sidegrades.
