Soulstone Survivors. Tuned for **prestige 76**: full unique kit + **Damnatus, Spire of Shadows** (P70). Primary path is **Firestarter Burn** — stack **Burn**, detonate with **Conflagrate**, cash **Wrathful Focus** on Lords. Not Doom-first, not Emberweaver-first.

## Why Firestarter Burn (not Damnatus / not Emberweaver)

- **Burn** is Pyro’s identity — Firestarter artifact **Phoenix Rebirth** applies Burn; Wrathful Focus **Draconic Flames** apply Burn + Shattered
- **Conflagrate** turns packed Burn into screen explosions (clear + Mh'thaeus / Lord check)
- **Searing Intensity** + **Elemental Flow** pay off hardest when everything is on fire
- **Damnatus** is the P70 toy — solid Doom / crit sidegrade, weaker than dedicated Burn + Conflagrate for Cathedral and general clear
- **Emberweaver** (Fragility) is a real power spike if crafted — see alt; not required for P76 Fire peak

## Passives — take / ban

### Prioritize

1. **Burn** chain — Fiery Amplification / Spontaneous Combustion / Ignition Point / Incinerate / Intense Fire
2. **Movement** (glass + Wrathful Focus hates getting hit)
3. **Cast frequency** / **multicast** / **area**
4. **Damage**
5. Some **max HP** / armor (class −20 HP, −15 armor)
6. Fire / Magical skill-chain upgrades

### Hard-ban / ban

- Main-ailment **Poison / Bleed / Doom** greed on this path
- Pure armor stacking before move + Burn are online
- **Skill Mastery** for types you already have
- Tanking hits “for the retaliate explosion” tree nodes — they fight Wrathful Focus

## How to play a run

1. Keep **Fire Slash**; lock **Combustion** + **Conflagrate**; fill Firestorm / Fiery Blades / Arcane Power.
2. Stack Burn on packs → **Conflagrate** when thick.
3. Fill **concentration** by not getting hit → walk the portal → dump **Ascended / Draconic Flames** on Lords.
4. Fix move early — paper with a flamethrower.
5. Try **Emberweaver Fragility**, **Damnatus Doom**, or **Stormcaller Electric** as sidegrades.

## Unholy Cathedral — cycle skill combos

See [`Unholy-Cathedral.md`](Unholy-Cathedral.md) for full mode mechanics (**4 cycles**, skill lockout, Unholy Powers, strip between cycles, Mh'thaeus). Mode comparison: [`Titan-Hunt-vs-Modes.md`](Titan-Hunt-vs-Modes.md).

Cathedral **strips actives/passives each cycle** and **locks out skills you already picked** for later cycles, so you cannot hold the Void Field 6-skill package all run. Build around **roles**, not fixed names. Keep Firestarter + the same Tenacity/Versatility runes; Unholy Powers between cycles are free stats — favor damage, cast freq, area, move. Cycle **4** actives also fight **Mh'thaeus** — save detonates / Burn-scaling nukes for then.

**Wrathful Focus still works** across cycles (ascension is not stripped). Play for concentration; cash Ascended on cycle bosses and Mh'thaeus.

**Every cycle, try to cover:** (1) Burn applicator · (2) AoE clear · (3) Burn detonate or Burn-scaling hit · (4) optional multicast / move buff.

Pick the combo that matches what the cycle pool actually offers.

### Combo A — Classic Burn detonate

Best when Fire tools show up (your default plan).

| Role | Prefer | Acceptable swaps |
| --- | --- | --- |
| Applicator | Fire Slash / Combustion / Fire Bolt | Fire Wall, Flamethrower |
| Clear | Firestorm / Flamethrower | Flame Wave, Chaotic Inferno |
| Detonate | **Conflagrate** | Meteor Shower / Fiery Blades if Conflagrate already locked |
| Soften | Fire Wall (Weakness) | Light Beam, Armor Shatter, anything Weakness / Exposed |
| Flex | Arcane Power / Bloodlust | Skip empty buff slots if pool is thin |

**Play:** stack Burn → Conflagrate when thick. If Conflagrate is locked from an earlier cycle, lean Combo B (Burn-scaling hits) or Combo C.

### Combo B — Burn-scaling smash (no Conflagrate)

Best when Conflagrate is already locked or never offered.

| Role | Prefer | Acceptable swaps |
| --- | --- | --- |
| Applicator | Combustion + Fire Slash | Fire Bolt, Fire Wall |
| Clear | Firestorm | Flamethrower, Flame Wave |
| Boss poke | **Meteor Shower** / **Fiery Blades** | Overcharged Blast if Electric pool |
| Soften | Weakness / Shattered sources | Fire Wall, Draconic Flames via Ascended |
| Flex | Arcane Power | Bloodlust |

**Play:** overstack Burn; sit Meteor / Fiery Blades on Mh'thaeus. Ascended Draconic Flames help fill Burn + Shattered for Searing Intensity.

### Combo C — Electric / Fragility / Doom bridge

Best when Fire is thin or already burned (locked), and Stormcaller / Emberweaver / Damnatus skills appear (or Unexpected Arsenal).

| Role | Prefer | Acceptable swaps |
| --- | --- | --- |
| Engine | Lightning Surge + Lightning Field | Arcane Storm + Runic Ember |
| Nuke | Overcharged Blast / Electric Strike | Shadow Grasp, Chaos Eruption |
| Clear | Dark Swarm / Chaotic Inferno | Chain Lightning |
| Flex | Bloodlust / Arcane Power | Any remaining Burn applicator as bridge |

**Play:** Dazed / Fragility / Doom for the cycle; still take Unholy Powers that boost damage / cast freq. Do not force Fire Mastery — you already have Fire.

### Cathedral pick order (any combo)

1. Grab a **detonate or boss skill** if you see it (**Conflagrate**, Meteor Shower, Fiery Blades, Overcharged Blast) — don’t “save” it for later; taking it early locks it out of cycle 4.
2. Fill **applicator + AoE** next (Combustion / Firestorm / Fire Slash).
3. Take **Arcane Power** / **Bloodlust** when the pool is otherwise filler.
4. Burn weak uniques early (Fire Walk if it appears, mediocre Chaos one-offs) so cycle 4 pool is cleaner.
5. Never lock a dead skill into cycle 4 just to fill a slot — reroll if you still have charges.

**Passives** still follow the main guide (Burn / move / cast freq / area / HP). Soft-ban off-ailments the same way. Unholy Powers: prefer damage, cast freq, area, move — same as a short Void clear.

**Rune note for Cathedral:** Endless Refill + Reroll Mastery matter more than Weapon Expert. Inclination: Fire still helps early cycles; expect to pivot roles when Fire is locked out.
