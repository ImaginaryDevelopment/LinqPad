Soulstone Survivors. Tuned for **prestige 71**: full weapon kit including **Might of the Mountains**. Primary path is **Immortal’s Staff** Singular Slam / **Prowess** — not Mountains-first (Earth/Colossal is the weaker unlock).

## Why Singular Slam (not Mountains / not Boomstick-first)

- **Expansive Throw** scales with **Prowess** twice (base Prowess amp + stack-scaled throw) — best MK kill skill you own
- **Spinning Staff** ×3–4 via **Singular Focus** = Prowess engine + **Shattered** + screen clear
- **Might of the Mountains** (P70) is craftable now, but Colossal mostly grows **area**, not damage; armor investment dilutes offense. Play it as a tanky sidegrade
- **Boomstick Bleed** remains excellent (see alt) — pick it if you prefer Shrapnel detonates over Prowess rollers
- Class **+25% area** + clones = map control while you stack Prowess

## Passives — take / ban

### Prioritize

1. **Damage** / **area** / **cast frequency** / **multicast** (Prowess stacking rate)
2. **Magnetic** + **movement**
3. **Fortifying Damage** / Resilience helpers (armor from casts — free on this spam)
4. Slam / Physical skill-chain passives
5. Clone duration / damage if offered
6. Some max HP only if dying — you are not Boomstick-fragile

### Soft-ban / ban

- **Crit chance / crit damage** greed (class −10% crit damage; Staff taxes crit)
- Main-ailment **Poison / Fire / Doom / Bleed** (wrong path — use Boomstick alt for Bleed)
- Armor stacking *instead of* damage (save armor greed for Mountains alt)
- **Skill Mastery** for Slam / Earth / Bomb / Electric / Chaos — native types

## How to play a run

1. Weapon Expert → Spinning Staff; lock **Expansive Throw**; duplicate Staff aggressively.
2. Collect **Yin/Yang** → clones while you circle packs.
3. Lords: keep Prowess high, aim **Expansive Throw** through them.
4. Do not pivot into Mountains mid-run unless you planned the armor path.
5. Farm Mountains if you want the tanky Earth experiment; Boomstick anytime for Bleed.
