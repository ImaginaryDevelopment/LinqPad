# Warder Primal Strike Hybrid — Support + Solo

**Warder** = Shaman + Soldier. Same co-op support toolkit (auras, totems, War Cry, low aiming), plus **Primal Strike** so they can solo when playing alone.

**Compare with:** [Warder Tanky Support (pure)](./Warder-Tanky-Support.md) (max support lean, weak alone).

## Playstyle

### Always (solo or co-op)
1. Toggle **Mogdrogen’s Pact** + **Field Command** (+ Squad Tactics).
2. Prefer **Stormcaller’s Pact** exclusive (lightning conversion / damage) for solo DPS.
3. Drop **Wendigo Totem** under your feet in fights.
4. Drop **Wind Devil** → keep **Raging Tempest** up (RR).
5. **War Cry** on scary packs / bosses.
6. Hold **Primal Strike** on whatever is in front of you.

### Co-op
Stand near the carry so auras overlap (~12m). You’re the taunt sponge; they do most of the melting.

### Solo
Same buttons — totem + leech + War Cry keep you alive while PS clears.

## Damage engine (solo enabler)

| Skill | Role |
| --- | --- |
| **Primal Strike** | Main attack — big lightning AoE smash |
| **Thunderous Strike** | 1-pt transmuter → removes PS cooldown (spam mode), *or* follow the cooldown PS variant in the 1.2 beginner grimtools |
| **Torrent / Storm Surge** | PS damage nodes |
| **Stormcaller’s Pact** | Exclusive — phys→lightning + lightning damage |
| **Brute Force** | 2H damage passive |

Weapon fantasy: **2H** lightning stick. Leveling hero item: **Korvan Storm Halberd** (Temple of Osyr / Map Room of Rahn).

## Skill priorities (skeleton)

| Phase | Spend on |
| --- | --- |
| **1–20** | Shaman. Early clear with Savagery / Devouring Swarm / Wind Devil. Unlock **Mogdrogen’s Pact**, start **Primal Strike** when available. Physique dump. |
| **20–40** | Open **Soldier**. **Field Command** + **Squad Tactics**. **War Cry**. Keep PS climbing. |
| **40–70** | Cap **Raging Tempest**, **Stormcaller’s Pact**, PS line, Wendigo breakpoints, Soldier defenses (**Menhir’s Will**, Military Conditioning, Scars of Battle). |
| **Endgame** | Support auras still high; PS + Stormcaller fully online. Resists overcapped; HP + DA comfortable. |

**Attributes:** mostly **Physique**.

**Wendigo breakpoints:** aim **5 / 9 / 12 / 15** ranks. Blood Pact **5** minimum for ADCtH.

## Devotion themes

Hybrid tank + lightning:

- Sailor’s Guide / Eel early for move speed
- Crab / Turtle / Behemoth for tank
- Chariot heal proc
- Tempest / Widow / lightning support as you gear up
- Bind heal/DA procs to auras or totem; DPS procs to Primal Strike / Wind Devil

Follow a beginner PS Warder grimtools path.

## Pairing with a Drain Essence Reaper

| Warder | DE Reaper |
| --- | --- |
| Holds aggro, auras, totem heal | Channels DE for kill speed |
| Squad Tactics → cast speed | Night’s Chill / cold RR |
| Can clear alone when Reaper is offline | Can clear alone when Warder is offline |

Stay stacked for aura overlap.

## Pairing with a Saboteur (base-game bomb carry)

See [Saboteur-Grenado-Warder-Partner.md](./Saboteur-Grenado-Warder-Partner.md).

| Warder | Saboteur |
| --- | --- |
| Holds aggro, auras, totem heal | Grenado / Thermite / Flashbang clear |
| Squad Tactics → cast speed | More bomb cycles |
| Raging Tempest → elemental RR | Cold/fire bombs hit harder |
| Can solo with Primal Strike | Can solo glassier with Blast Shield + kite |

Stay stacked for aura overlap — Saboteur shouldn’t Shadow Strike out of the bubble.
