# Drain Essence Reaper — Study Notes

Grim Dawn chase build. **Reaper** = Necromancer + Nightblade. Main skill: **Drain Essence** (channel). Current meta lean: **Cold DE** (Chillwhisper endgame) — also a strong **Vitality DE** variant.

## Why this build

| | |
| --- | --- |
| **Fantasy** | Stand in / near packs, hold Drain Essence, melt everything while leeching |
| **Mobility** | Nightblade tools + movement cult augment; channel while repositioning; not a pure stand-still turret |
| **Scale** | One of the best SR / Crucible farmers for cost and button count |
| **Difficulty** | Low piloting — “automatic” RR on cold path; still dodge big telegraphs |
| **Masteries** | Start Necromancer → add Nightblade ~20–30 when Pneumatic Burst comes online |

**Pros**

- Smooth from level ~2
- Simple: mostly DE + keep buffs up
- Controller-friendly
- Strong MI / faction gear support while leveling
- Cold endgame RR mostly on buffs/auras (set and forget)

**Cons**

- DE does **not** break objects (Shift-move or movement augment)
- Chillwhisper craft needs Celestial Lotuses
- Channeling can feel boring if you hate holding one button
- Patch **1.3** soft-nerfs DE — still considered very strong / “EZ mode” per guide comments

## Core idea (how damage works)

1. **Drain Essence** is the engine — hard-cap the skill **and** its important nodes when conversion allows.
2. Stack **Offensive Ability (OA)** hard — DE has big innate crit damage; OA is how you scale.
3. Stack **life** + **leech** — you are a leech tank, not a glass laser.
4. **Do not** chase early %damage or flat weapon-damage boosters that don’t feed DE.
5. **Hungering Reach** = extra targets (soft breakpoint ~**10** points early).
6. **Spectral Binding / Spectral Wrath** = huge life + OA package from Necro.
7. **Pneumatic Burst** (Nightblade) = secondary potion + total speed + OA — **cooldown management**, don’t spam it on CD for no reason; keep the buff up, save the rest for spikes.
8. **Blade Spirits** support clear / devotion procs / passive leech at endgame (cold Chillwhisper setups).

**Wrong paths people take**

- Amarasta’s Blade Burst / Bone Harvest as “flat damage amp” for DE — interrupts channel and is the wrong damage model
- Skipping flat / aura **resist reduction** at endgame
- Dumping points into Decomposition before you have **vitality → cold** conversion (wastes energy)

## Skill priorities (cold leveling skeleton)

Order of ideas, not exact point dump every level:

| Phase | Focus |
| --- | --- |
| **1–10** | Necro bar + **Drain Essence** → unlock **Hungering Reach** and dump it |
| **10–20** | Hungering Reach → **~10** (soft breakpoint), DE **16/16**, start **Spectral Binding** |
| **20–30** | Finish Binding + **Spectral Wrath**; open **Nightblade** → rush **Pneumatic Burst** |
| **30+** | Nightblade quality of life / defenses; skip Decomposition until conversion |
| **~50–60** | With **Gargoyle Waistguard** (vit→cold) unlock full DE nodes including Decomposition |
| **Endgame** | Cap DE nodes, Blade Spirits support, Master of Death exclusive, Nightblade utility |

Keep **Ill Omen** / occasional Necro debuffs light on cold auto-RR setups — vitality variants use more active RR (see below).

## Two endgame flavors

### A) Cold Chillwhisper Reaper (recommended study path)

- Full **Chillwhisper** set (craft — Celestial Lotuses)
- Cold DE + Blade Spirits
- Most RR “on” via auras/set — minimum piano
- Ranked among strongest channel farmers for **price + skill requirement**
- Budget L100 setup can farm **SR 26–27**; full setup does **SR 30–31** comfortably (videos on guide)

**Play:** Keep Spectral buffs + Pneumatic Burst logic, hold DE, move between packs with augment / NB tools.

### B) Vitality DE Reaper (mad_lee bonus)

- Bigger raw DE / OA stack; less passive RR than Ritualist “Drainmaster”
- Very comfortable — often only occasional **Ill Omen** interrupting channel (no Siphon Souls)
- Needs shoulders that hard-cap Spectral Wrath (guide notes this as the downside)
- Proven: SR 30–31 ~4:19, Ravager ~1:24, naked Cruc 150–170

**Play:** Soften with Ill Omen when needed → DE channel → reposition.

Pick **cold** if you want the smoothest SSF/beginner → Top20 farmer path. Pick **vitality** if you prefer non-set MI puzzle gearing and higher raw channel comfort.

## Budget → endgame farming loop (cold)

1. Hit 100 with campaign + Elite shrines / reputation
2. Totem route for T3 component BPs, Intrepid Boots BP, Emberguard Gloves BP
3. Craft stepping-stone boots/gloves (`of Celerity` gloves; life/res boots)
4. Shop **Living rings** at Vinelton (Ancient Grove reset trick)
5. Double-cold (or ele+cold) weapon
6. Farm **Impervious** prefix somewhere (often Solael guardian pants)
7. Assemble Chillwhisper + off-pieces → push SR 26+ then 30–31

SSF tip from guide: long SR sessions abuse anti-dupe better than constantly resetting dungeons.

## Stat checklist (endgame study targets)

Aim while reading grimtools:

- **OA** very high (crit is the DE multiplier)
- **HP** comfortable leech-tank range (20k+ is modern baseline; more is safer)
- **Resist overcaps** — especially phys / chaos / aether as content demands
- **Cast speed** — channel DPS and smooth play
- **Energy** — Scales devotion / Insight / ectoplasm early; don’t starve DE
- **Move speed** — boots + augments (this is the “mobility” half of the fantasy)
