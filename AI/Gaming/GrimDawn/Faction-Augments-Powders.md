# Grim Dawn — Faction Augments / Powders Reference

Searchable reference for **augments** (faction powders, dusts, venoms, ashes). Separate from **components** (crafted inserts).

**Sources:** [Grim Dawn Wiki — Augment](https://grimdawn.fandom.com/wiki/Augment)

---

## Quick rules

| Topic | Detail |
| --- | --- |
| Slots | **Weapon** → 1H weapon, shield, caster off-hand. **Potent** → **2H only**. **Accessory** → ring/amulet. **Armor** → all armor except shield. |
| One per item | One augment + one component max per piece. |
| Reputation | **Friendly** (ilvl 40) → basic weapon/jewelry. **Honored** (50/65) → rare weapon/jewelry. **Revered** (70/90) → armor powders + top tier. |
| Remove / swap | Overwrite with new augment, or Inventor remove. Item kept; powder **not** refunded. |
