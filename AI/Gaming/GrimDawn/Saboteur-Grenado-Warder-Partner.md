# Saboteur — Bomb Clear (Warder Partner)

**Saboteur** = Demolitionist + Nightblade. **Base-game** masteries (no DLC required to play the class). Fantasy: trap → flash → **blow packs up** with Grenado / Canister / Thermite, Shadow Strike for mobility.

**Designed to pair with:** [Warder Primal Strike Hybrid](./Warder-Primal-Strike-Hybrid.md) (or [pure Warder support](./Warder-Tanky-Support.md)) — Warder holds faces and auras; you lob bombs from aura range.

## Why this with a Warder

| Need | Saboteur answer |
| --- | --- |
| Pack clear while Warder tanks | **Grenado / Canister / Thermite** — big AoE bombs |
| Stay in aura range (~12m) | Mid-range caster; Shadow Strike to rejoin if you drift |
| Use Warder buffs | **Squad Tactics** cast speed = more bombs; Wendigo heals your glass body; War Cry keeps aggro off you |
| Elemental RR synergy | **Cold** (or fire) bombs love **Raging Tempest** |
| Solo when Warder offline | Yes — Blast Shield + Flashbang + kite; squishier than Warder alone |
| Base game | **Yes** — Demo + Nightblade |

**Roster note:** combo is **new** for you. Demo appears on Gonorrhea (Pyromancer); Nightblade on Barbie / LetsDoAcid — same masteries used elsewhere, different dual class.

## Playstyle

### Co-op (with Warder)
1. Stay near Warder so auras overlap.
2. Warder War Cry / totem / holds the pack.
3. You: **Thermite Mine** under the pile → **Flashbang** → **Grenado** (and **Canister Bomb** as skilled) into the middle.
4. Optional: **Blade Trap** to pin runners, then bomb the trapped clump.
5. **Shadow Strike** to reposition / stick to the Warder’s pocket if something peels you.
6. Keep **Pneumatic Burst** + Demo buffs up; **Blast Shield** when it procs / for panic.

**Rhythm matters:** trap / Thermite / Flashbang **first**, then Grenado. Damage spikes when bombs hit debuffed / trapped packs (Cold War Story callout).

### Solo
Same loop, but you must kite more. Don’t stand in the middle like a Battlemage. Blast Shield + Flashbang impaired aim are your peels.

### Not this file
- Pure **Fire Strike** dual-wield melee Saboteur — viable, different fantasy (see Justice / Ember’s Calling guides).
- **Rimetongue pierce** Grenado — endgame gear pivot after you’re comfortable cold/fire bombing.

## Core idea

1. **Grenado** (and often **Canister Bomb**) = main clear engine.
2. **Thermite Mine** = fire RR / shred layer — drop it even on cold builds when the GT uses it.
3. **Flashbang** = soft CC / impaired aim — 1-pt+ for tough packs.
4. **Blast Shield** = major fail-safe — don’t skip (Cold War Story pushes high ranks + CDR).
5. **Pneumatic Burst** = heal + speed + OA — always up.
6. **Shadow Strike** = mobility (+ damage); not your only button.
7. Nightblade utility: **Veil of Shadow**, Dual Blades only if the GT is melee; caster Sabos often light on WPS.
8. Demo exclusive: usually **Ulzuin’s Wrath** / Vindictive Flame package as points allow — follow GT.

## Skill priorities (skeleton)

| Phase | Spend on |
| --- | --- |
| **1–20** | **Demolitionist** first. **Blackwater Cocktail** / early bombs (Sabotinha) or Fire Strike filler → unlock **Grenado** / **Canister** ASAP. **Blast Shield** early. Physique dump. |
| **20–35** | Open **Nightblade**. Rush **Pneumatic Burst**. Start **Shadow Strike** for move+damage. Keep bombs climbing. |
| **35–60** | Cap / near-cap **Grenado** or **Canister** + key nodes. **Thermite Mine**. **Flashbang**. Soft-cap PB. Raise Blast Shield toward comfortable breakpoint (~10–14/12 per GT). |
| **60–100** | Mirror your chosen GT (**Sabotinha** fire or **Cold War Story**). Add Blade Trap if using trap→bomb. Resist caps + energy before vanity %damage. |

**Attributes:** mostly **Physique**. Spirit for energy if casting heavy. Cunning only for gear.

## Devotion themes

Caster bomb Saboteur:

- Early: Sailor’s Guide / Eel (move), Scholar’s Light or similar energy if needed
- Sustain: Ghoul / Bat / Turtle / Behemoth lean — Saboteur is glass
- DPS: cold or fire tree matching your damage (Amatok / Ultos / Korvaak / Leviathan-style cold AoE, etc.)
- Bind RR / nuke procs to **Grenado** or **Thermite**; heals to PB or a permanent buff

Follow the Cold War Story or fire beginner devotion map — don’t freestyle until resists are capped.

## Gear priorities

| Priority | Look for |
| --- | --- |
| **Resists / HP / DA** | First — bombs don’t help if you’re dead |
| **Cast speed + OA** | More Grenados, better crits |
| **% Cold or % Fire** + skill modifiers to Grenado / Canister / Thermite | Damage identity |
| **CDR** | Blast Shield + bomb uptime |
| Weapon / OH | Caster 1H + focus **or** DW — match GT (cold casters often shield/focus) |
| Medal | Movement rune (Bysmiel leap / Dreeg Vector / Solael charge — FG emblems if you own FG; otherwise any move skill you have) |

**Leveling fillers:** fire/cold epics, Demo faction gear, anything with +Grenado / +Demo skills. Don’t wait on Rimetongue / Justice to enjoy the class.

**Endgame forks**

| Path | Set / idea | Notes |
| --- | --- | --- |
| **Cold Grenado** (recommended start) | Cold War Story greens / Hyrian-style setups | Strong clear, learn the rhythm |
| **Fire Grenado / BWC** | Beginner fire Sabo GTs | Same bomb feel, fire RR from Thermite shines |
| **Pierce Rimetongue** | Rimetongue + Gildor’s | Optional later; level cold first |
| **Fire Strike DW** | Justice / Ember’s Calling | Different playstyle — hold attack, not this guide’s focus |

## Pairing with Warder (cheat sheet)

| Warder | Saboteur |
| --- | --- |
| Holds aggro, auras, Wendigo heal | Bombs the tagged pack |
| Squad Tactics → **cast speed** | More Grenado cycles |
| Raging Tempest → elemental RR | Cold/fire bombs hit harder |
| War Cry sponge | You stay at mid-range and don’t facetank |
| Can solo with Primal Strike | Can solo with bombs + Blast Shield (glassier) |

Stay stacked. If you Shadow Strike across the map, you leave the aura bubble — don’t.

## Clear & survival (honest)

| | Expectation |
| --- | --- |
| **Trash clear** | Excellent once Grenado + Thermite rhythm clicks |
| **Bosses** | Good if bombs reset / you keep debuffs up; weaker than dedicated ST channels if you miss CD rhythm |
| **Survival** | Medium — Blast Shield + Flashbang + Warder heal. Solo is “kite or die” vs Bottlemage |
| **APM** | Medium — more buttons than Fire Strike hold-LMB, less than full piano Apostate |
