# Warder Tanky Support — Co-op Partner Build

**Warder** = Shaman + Soldier. Built for someone playing **with** a damage carry (e.g. Drain Essence Reaper) who wants to be useful without fast reactions or precise targeting.

Primary sources / inspiration:

- [WyreZ — Support Builds (healing / tank-support hybrids)](https://forums.crateentertainment.com/t/1-1-9-1-wyrez-guide-to-support-builds-healing-supports-and-how-to-build-them/109607)
- Community co-op Warder notes (War Cry taunt + Field Command + Wendigo Totems)

---

## Why this instead of other Shaman combos

| Combo | Verdict for slow / tanky support |
| --- | --- |
| **Warder (Shaman + Soldier)** | **Best fit** — tankiest, War Cry taunt, Field Command party buff, almost no aiming |
| Conjurer (Shaman + Occultist) | Better raw RR (Curse of Frailty) — still good, but more “cast on packs” and less brick-wall |
| Ritualist (Shaman + Necro) | More leech/summons; less classic aura support |
| Elementalist (Shaman + Demo) | More DPS identity |

**Pick Warder** if the partner’s job is: stand near the Reaper, stay alive, keep auras up, drop totems, press War Cry when things get spicy.

---

## Playstyle (low APM)

This is **not** a skillshot build.

1. Turn on auras once: **Mogdrogen’s Pact**, **Field Command** (+ Squad Tactics).
2. Walk into packs with the carry.
3. Drop **Wendigo Totem** at your feet (heal aura — needs enemies in range to heal).
4. Drop **Wind Devil(s)** near yourself — they chase; invest **Raging Tempest** for RR / slow.
5. Press **War Cry** when surrounded or before a nasty pack — taunt + enemy damage cut. No targeting.
6. Optional panic: **Menhir’s Will** / **Overguard** if skilled.

That’s the whole loop. Left-click can be a simple auto / Savagery / Forcewave for threat tags — accuracy does not matter.

## What you give the party

### Buffs (stay near allies — ~12m auras)

| Skill | What it does for the team |
| --- | --- |
| **Mogdrogen’s Pact** | Flat HP regen, energy regen, small damage — classic Shaman aura |
| **Heart of the Wild** | Big **% health** + % regen on the Pact aura |
| **Oak Skin** | Armor / pierce res (personal-leaning but strong tank glue) |
| **Field Command** | Armor, OA, DA for nearby allies |
| **Squad Tactics** | Attack / cast speed for nearby allies — huge for a channeler |
| **Wendigo Totem** | % HP heal in a circle (place in the fight, not across the map) |
| **Emboldening Presence** (Briarthorn, optional) | Extra ally OA / phys if you run the pet |

### Debuffs / control (easy buttons)

| Skill | What it does |
| --- | --- |
| **War Cry** | Taunt + reduces enemy damage dealt — you become the sponge |
| **Break Morale** | Skill disruption / further softening (1–few points often enough) |
| **Wind Devil → Raging Tempest** | Lightning / elemental-leaning RR + attack-speed slow on enemies near the devil |
| **Devouring Swarm** (optional) | Vitality / bleed RR if you want more amp; cast roughly at packs |

Your DE Reaper already brings cold RR (Night’s Chill etc.). This Warder’s job is **survivability + speed/OA/DA buffs + taunt**, not replacing their RR package.

## Skill priorities (skeleton)

Order of ideas while leveling:

| Phase | Focus |
| --- | --- |
| **1–20** | Shaman first. **Mogdrogen’s Pact** early, **Wendigo Totem**, **Devouring Swarm** or **Wind Devil** for clear. Physique dump. |
| **20–40** | Open **Soldier**. Rush **Field Command** + **Squad Tactics**. Pick up **War Cry**. Keep Pact / Heart of the Wild climbing. |
| **40–70** | Cap support nodes: Pact line, Field Command line, Wendigo, Wind Devil + **Raging Tempest**. Soldier defenses (**Menhir’s Will**, armor passives). |
| **Endgame support lean** | High HP + regen + DA. Auras maxed. War Cry reliable. Damage skills are optional fillers for threat / clear. |

**Attributes:** mostly **Physique**. Cunning/Spirit only for gear reqs.

**Skip / deprioritize for this fantasy:** glass DPS Primal Strike stacks, fancy rotation melee, anything that needs constant retargeting.

## Devotion themes (support tank)

Aim for:

- **Behemoth** / heal-on-hit or regen constellations
- **Turtle** / **Crab** / DA and armor
- **Chariot** heal proc (nice with totems / auras)
- Optional RR helpers if points allow (**Viper**, etc.)

Exact shrine path can follow any solid Warder leveling grimtools; prioritize **don’t die** over DPS constellations.

---

## Gear priorities (support tank)

Chase **life, regen, DA, armor, resists** — not personal DPS.

| Slot priority | Look for |
| --- | --- |
| Armor / jewelry | Health, health regen, DA, resists |
| Medal | Movement augment (any cult you like — Charging Bull is fine) |
| Relic | Defensive / regen / +skills to Shaman or Soldier |
| Components | Life, resist, absorb — Scaled Hide, Silk Swatch, etc. |

Faction gear while leveling is fine (same idea as other tanky leveling routes). Endgame can stay on strong MI / faction / budget legendaries; this role does not need a perfect DPS set.

## Pairing with Drain Essence Reaper

| You (Warder) | Them (Cold DE Reaper) |
| --- | --- |
| Stand in the middle, hold aggro with War Cry | Channel Drain Essence safely |
| Squad Tactics = more cast speed for their channel | Night’s Chill / cold RR |
| Wendigo Totem under the pack | Leech + OA stacking |
| You die last | They melt packs |

Stay roughly on top of each other so auras overlap. If they kite far ahead, your buffs drop off (~12m).

## Alternate: Conjurer support (if they want more debuffs)

**Shaman + Occultist** if the partner prefers **Curse of Frailty + Vulnerability** (huge RR) and **Blood of Dreeg**, and is okay clicking curses near packs.

Still low targeting vs a pure DPS build, but **less tanky** than Warder and War Cry taunt is gone.

Only pick this if “more damage amp” beats “I am the brick wall.”

> Note: roster character **The Shocker** is listed as Ritualist (Shaman + Occultist) in `Characters.md` — that mastery pair is actually **Conjurer**. Worth fixing the label later; that alt could soft-respec toward support Conjurer if you don’t want a brand-new Warder.
