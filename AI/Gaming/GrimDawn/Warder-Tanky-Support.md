# Warder Tanky Support — Co-op Partner (Pure Support)

**Warder** = Shaman + Soldier. Built for someone playing **with** a damage carry who wants to be useful without fast reactions or precise targeting.

**Compare with:** [Warder Primal Strike Hybrid](./Warder-Primal-Strike-Hybrid.md) (same masteries, can solo).

## Playstyle (low APM)

This is **not** a skillshot build.

1. Turn on auras once: **Mogdrogen’s Pact**, **Field Command** (+ Squad Tactics).
2. Walk into packs with the carry.
3. Drop **Wendigo Totem** at your feet (heal aura — needs enemies in range to heal).
4. Drop **Wind Devil(s)** near yourself — they chase; invest **Raging Tempest** for RR / slow.
5. Press **War Cry** when surrounded or before a nasty pack — taunt + enemy damage cut. No targeting.
6. Optional panic: **Menhir’s Will** / **Overguard** if skilled.

Left-click can be a simple auto / Savagery / Forcewave for threat tags — accuracy does not matter. Damage is optional filler.

## What you give the party

### Buffs (stay near allies — ~12m auras)

| Skill | What it does for the team |
| --- | --- |
| **Mogdrogen’s Pact** | Flat HP regen, energy regen, small damage — classic Shaman aura |
| **Heart of the Wild** | Big **% health** + % regen on the Pact aura |
| **Oak Skin** | Armor / pierce res (strong tank glue) |
| **Field Command** | Armor, OA, DA for nearby allies |
| **Squad Tactics** | Attack / cast speed for nearby allies — huge for a channeler |
| **Wendigo Totem** | % HP heal in a circle (place in the fight, not across the map) |
| **Emboldening Presence** (Briarthorn, optional) | Extra ally OA / phys if you run the pet |

### Debuffs / control (easy buttons)

| Skill | What it does |
| --- | --- |
| **War Cry** | Taunt + reduces enemy damage dealt — you become the sponge |
| **Break Morale** | Skill disruption / further softening (1–few points often enough) |
| **Wind Devil → Raging Tempest** | Lightning / elemental-leaning RR + attack-speed slow |
| **Devouring Swarm** (optional) | Vitality / bleed RR; cast roughly at packs |

Job is **survivability + speed/OA/DA buffs + taunt**, not competing for kill credit.

## Skill priorities (skeleton)

| Phase | Focus |
| --- | --- |
| **1–20** | Shaman first. **Mogdrogen’s Pact** early, **Wendigo Totem**, **Devouring Swarm** or **Wind Devil** for clear. Physique dump. |
| **20–40** | Open **Soldier**. Rush **Field Command** + **Squad Tactics**. Pick up **War Cry**. Keep Pact / Heart of the Wild climbing. |
| **40–70** | Cap support nodes: Pact line, Field Command line, Wendigo, Wind Devil + **Raging Tempest**. Soldier defenses (**Menhir’s Will**, armor passives). |
| **Endgame support lean** | High HP + regen + DA. Auras maxed. War Cry reliable. Damage skills stay optional. |

**Attributes:** mostly **Physique**. Cunning/Spirit only for gear reqs.

**Skip / deprioritize:** glass DPS Primal Strike stacks, fancy rotation melee, anything that needs constant retargeting.

## Devotion themes (support tank)

- **Behemoth** / heal-on-hit or regen constellations
- **Turtle** / **Crab** / DA and armor
- **Chariot** heal proc
- Optional RR helpers if points allow (**Viper**, etc.)

Prioritize **don’t die** over DPS constellations.

---

## Gear priorities (support tank)

Chase **life, regen, DA, armor, resists** — not personal DPS.

| Slot priority | Look for |
| --- | --- |
| Armor / jewelry | Health, health regen, DA, resists |
| Medal | Movement augment (Charging Bull is fine) |
| Relic | Defensive / regen / +skills to Shaman or Soldier |
| Components | Life, resist, absorb |

Faction / budget gear is enough. This role does not need a perfect DPS set.

## Pairing with a Drain Essence Reaper

| Warder (support) | DE Reaper |
| --- | --- |
| Hold aggro with War Cry | Channel Drain Essence |
| Squad Tactics → cast speed | Night’s Chill / cold RR |
| Wendigo Totem under the pack | Leech + OA stacking |
| Die last | Melt packs |

Stay stacked so auras overlap (~12m).
