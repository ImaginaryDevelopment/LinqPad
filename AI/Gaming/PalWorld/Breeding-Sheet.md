# Breeding Sheet (Palworld 1.0)

Paldex ID, elements, rideability, breed rank, food tier, and common/fixed traits.

**Coverage:** full **1.0** Paldex (**289** pals). Dex was renumbered in 1.0 (e.g. Jetragon **#202**). Variant suffixes (**B/C**) mark regional forms sharing a number.

**Breed rank** = breeding power key (parent average -> nearest child). Blank = not in legacy export.

**Food** = hunger tier 1-10 where known. **Glutton** stacks on top as a passive.

**Ride:** Fly / Ground / Water / Glider / Ground/Water / `-` = not rideable. See [Mounts.md](./Mounts.md).

---

## Fixed / extremely common traits

| Trait | Typical carriers | Effect |
| --- | --- | --- |
| **Glutton** | Relaxaurus / Relaxaurus Lux (**always**) | Hunger drains +10% faster |
| **Coward** | Cattiva (**always**) | Attack -10% |
| **Legend** | Frostallion, Frostallion Noct, Jetragon, Necromus, Paladius, Neptilius, Panthalus | Atk/Def +20%, Move +15% |
| **Element Emperors** | Anubis, Blazamut, Lyleen, Jormuntide, Orserk, Frostallion, Paladius, Jetragon, Necromus / Frostallion Noct, Hartalis (Savior) | Big matching-element damage |
| **Nocturnal** | Nearly all **Dark** pals | Work through the night |
| **Hard Skin** | Astegon, Digtoise, Warsect line | Defense +10% |
| **Hooligan** | Gorirat / Gorirat Terra | Atk +15%, Work Speed -10% |
| High **Food** (8-9) | Big legendaries / mounts | Eat constantly; plan feedboxes |

Breeding tip: fixed drawbacks (**Glutton**, **Coward**) still inherit. Scrub with a clean parent or Surgery Table.
