# Mining Pals (Palworld 1.0)

Base miners (Mining work suitability) plus party helpers for **carry weight**, **ore/stone weight**, and **player mining speed**.

**Wild min** = lowest documented wild / Alpha level (PalMods / Mounts notes). Region spawns go higher. `—` = unknown / breed / raid-gated.

Mining suitability gate (approx):

| Mining Lv | Can extract |
| ---: | --- |
| 1 | Stone, Paldium |
| 2 | Ore, Sulfur |
| 3–4+ | Coal, Pure Quartz (and faster on everything) |

See also: [Breeding-Sheet.md](./Breeding-Sheet.md) · [Mounts.md](./Mounts.md)

---

## Quick picks

| Role | Pick | Why |
| --- | --- | --- |
| Early stone / paldium | **Cattiva**, **Fuddler**, **Rushoar**, **Depresso** | Mining 1; Fuddler/Rushoar also buff *you* while exploring |
| Mid base ore | **Digtoise**, **Tombat**, **Penking**, **Dumud** | Digtoise is mining-only (won’t wander to other jobs) + Drill Crusher in the field |
| Late base ore | **Aegidron** (8), **Astegon / Blazamut / Knocklem** (7), **Anubis** (6) | Top suitability; Anubis also Handiwork 4 for crafting lines |
| Carry more ore home | **Wumpo / Wumpo Botan** (+120), **Broncherry / Kingpaca** (+100), **Lunaris / Cattiva / Kikit** | Need matching saddle / gear for carry skills |
| Ore feels lighter | **Reptyro** (ores), **Turtacle** (ore), **Fuddler** (stone), **Turtacle Terra** (sulfur/coal) | Party skills; usually **do not stack** with same effect |
| Active node smash | **Digtoise** (Drill Crusher), **Rushoar** (Hard Head on stone while ridden) | Player-led mining, not base assignment |

**Passive:** **Mine Foreman** (+25% player mining) can roll on any Pal — breed/Surgery it onto your field crew.

## Progression checklist

1. **Lv 1–15:** Cattiva (carry) + Fuddler (mine buff / light stone) + Rushoar (stone mount) + Depresso/Tombat for night base mining.
2. **Ore unlock:** Dumud or Penking (Mining 2–3) on Ore nodes / Mining Site.
3. **Field ore:** Digtoise Drill Crusher + Reptyro/Turtacle ore weight + a Wumpo/Broncherry for bag space.
4. **Endgame base:** Aegidron / Astegon / Knocklem / Blazamut; keep Anubis if you still need Handiwork on the same base.
